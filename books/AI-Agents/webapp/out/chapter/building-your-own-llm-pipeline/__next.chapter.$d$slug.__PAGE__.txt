## Why Build Your Own Pipeline?

### The Three Options

When deploying AI agents, you have three options for the language model:

| Option | Pros | Cons | Best For |
|--------|------|------|----------|
| **API (OpenAI, Anthropic, etc.)** | Easy setup, no infrastructure, always updated | Expensive at scale, data leaves your servers, rate limits | Prototyping, low-volume apps |
| **Self-Hosted Open Source** | Full control, data privacy, no per-token cost | Requires GPU infrastructure, model maintenance | Production apps with privacy needs |
| **Fine-Tuned Custom Model** | Best performance on specific tasks, can be smaller and faster | Requires training data, expertise, ongoing maintenance | Domain-specific high-volume tasks |

### When to Build Your Own Pipeline

Consider building your own pipeline when:

1. **Cost** — You are spending more than $1,000/month on API calls and the volume keeps growing
2. **Privacy** — Your data cannot leave your infrastructure (healthcare, finance, government)
3. **Latency** — You need sub-100ms response times that API round-trips cannot guarantee
4. **Specialization** — You need a model that performs exceptionally well on a narrow domain
5. **Reliability** — You cannot depend on third-party API availability

### The Pipeline Architecture

```
┌─────────────────────────────────────────────────────────┐
│                   LLM PIPELINE                          │
│                                                         │
│  ┌──────────┐   ┌──────────┐   ┌──────────┐            │

```

## Fine-Tuning Basics

### What Is Fine-Tuning?

Fine-tuning is the process of taking a pre-trained language model and continuing the training on your specific data. Instead of teaching the model language from scratch, you teach it your specific task.

Think of it like this:

```
Pre-training:  Teaching an English person to speak French
               (massive amount of general French education)

Fine-tuning:   Teaching that French speaker to be a chef
               (focused training on culinary vocabulary and recipes)
```

### Types of Fine-Tuning

```
┌─────────────────────────────────────────────────┐
│              FINE-TUNING SPECTRUM                │
│                                                 │
│  Full Fine-Tune ◀─────────────────▶ LoRA/QLoRA  │
│                                                 │
│  • Updates ALL weights        • Updates small    │
│  • Needs massive GPU           subset of weights │
│  • Best performance           • Needs less GPU   │
│  • Most expensive             • Near-best perf   │
│  • Risk of catastrophic       • Much cheaper     │
│    forgetting                 • Faster training  │
│                                                 │
│  Use when: $$$$$$            Use when: $$       │
│  (rare, research)            (most production)  │
└─────────────────────────────────────────────────┘
```

### What You Need

| Requirement | Minimum | Recommended |
|-------------|---------|-------------|
| GPU VRAM | 8 GB (QLoRA) | 24-48 GB |
| Training Data | 100 examples | 1,000-100,000 examples |
| Training Time | Minutes (small data) | Hours to days |
| Skills | Python basics | ML fundamentals |

## LoRA and QLoRA Explained Simply

### LoRA (Low-Rank Adaptation)

LoRA works by adding small trainable layers to the model while keeping the original weights frozen.

```
Original Model (frozen):
┌──────────────────────────────────┐
│  Weight Matrix W (4096 × 4096)   │
│  = 16,777,216 parameters        │
│  ❄️ FROZEN — not updated        │
└──────────────────────────────────┘

LoRA Adaptation (trainable):
┌──────────────────────────────────┐
│  Matrix A (4096 × 16) = 65,536  │
│  Matrix B (16 × 4096) = 65,536  │
│  Total = 131,072 parameters     │
│  🔥 TRAINABLE — updated during  │
│     fine-tuning                 │
└──────────────────────────────────┘

Instead of training 16M parameters,
you train only 131K parameters!
That's 128x fewer parameters to update.
```

### QLoRA (Quantized LoRA)

QLoRA takes LoRA further by loading the base model in 4-bit precision:

```
Full Precision (FP16):    1 model = 14 GB (for 7B model)
4-bit Quantization (QLoRA): 1 model = 3.5 GB (for 7B model)

┌──────────────────────────────────────────────┐
│              QLoRA Process                    │
│                                              │
│  1. Load base model in 4-bit (QLoRA4)        │
│     → Uses 3.5 GB instead of 14 GB          │
│                                              │
│  2. Add LoRA adapters (trainable)            │
│     → Small overhead (~100 MB)               │
│                                              │
│  3. Fine-tune only the LoRA adapters         │
│     → Fits on a single consumer GPU!         │
│                                              │
│  4. Merge LoRA weights back for serving      │
│     → Back to full precision for inference   │
└──────────────────────────────────────────────┘
```

### Rank: The Key Hyperparameter

The "rank" determines how many parameters the LoRA adapter has:

| Rank | Parameters (7B model) | Quality | Speed | VRAM |
|------|----------------------|---------|-------|------|
| 4 | ~2M | Basic | Fastest | ~4 GB |
| 8 | ~4M | Good | Fast | ~4 GB |
| 16 | ~8M | Great | Medium | ~5 GB |
| 32 | ~16M | Excellent | Slower | ~6 GB |
| 64 | ~32M | Best | Slowest | ~7 GB |

Rule of thumb: Start with rank 16 and increase if you need better quality.

### Data Quality Checklist

```python
class DataQualityChecker:
    """Check and improve training data quality."""

    def __init__(self):
        self.issues = []

    def check_dataset(self, data: list[dict]) -> dict:
        """Run all quality checks on the dataset."""
        self.issues = []

        self._check_size(data)
        self._check_format(data)
        self._check_duplicates(data)
        self._check_length(data)
        self._check_balance(data)
        self._check_language(data)

        return {
            "total_examples": len(data),
            "issues_found": len(self.issues),
            "issues": self.issues,
            "score": max(0, 100 - len(self.issues) * 10),
        }

    def _check_size(self, data):
        if len(data) < 100:
            self.issues.append({
                "severity": "warning",
                "message": f"Dataset has only {len(data)} examples. "
                          f"Recommend at least 100."
            })
        if len(data) > 100000:
            self.issues.append({
                "severity": "info",
                "message": f"Large dataset ({len(data)} examples). "
                          f"Consider sampling for faster iteration."
            })

    def _check_format(self, data):
        for i, example in enumerate(data[:10]):  # Check first 10
            if "messages" not in example:
                self.issues.append({
                    "severity": "error",
                    "message": f"Example {i} missing 'messages' field"
                })
                continue

            messages = example["messages"]
            if not messages:
                self.issues.append({
                    "severity": "error",
                    "message": f"Example {i} has empty messages"
                })
                continue

            last_role = None
            for msg in messages:
                if "role" not in msg or "content" not in msg:
                    self.issues.append({
                        "severity": "error",
                        "message": f"Example {i}: message missing role/content"
                    })
                if last_role == "user" and msg.get("role") == "user":
                    self.issues.append({
                        "severity": "warning",
                        "message": f"Example {i}: consecutive user messages"
                    })
                last_role = msg.get("role")

    def _check_duplicates(self, data):
        seen = set()
        duplicates = 0
        for example in data:
            key = json.dumps(example, sort_keys=True)
            if key in seen:
                duplicates += 1
            seen.add(key)

        if duplicates > 0:
            self.issues.append({
                "severity": "warning",
                "message": f"Found {duplicates} duplicate examples. "
                          f"Remove them for better training."
            })

    def _check_length(self, data):
        lengths = []
        for example in data:
            total_chars = sum(
                len(msg.get("content", ""))
                for msg in example.get("messages", [])
            )
            lengths.append(total_chars)

        if lengths:
            avg = sum(lengths) / len(lengths)
            short = sum(1 for l in lengths if l < 50)
            long = sum(1 for l in lengths if l > 10000)

            if short > len(data) * 0.1:
                self.issues.append({
                    "severity": "warning",
                    "message": f"{short} examples are very short (<50 chars)"
                })

            if long > len(data) * 0.1:
                self.issues.append({
                    "severity": "warning",
                    "message": f"{long} examples are very long (>10K chars)"
                })

    def _check_balance(self, data):
        """Check if assistant responses are well-distributed."""
        response_lengths = []
        for example in data:
            messages = example.get("messages", [])
            assistant_msgs = [
                m for m in messages if m.get("role") == "assistant"
            ]
            if assistant_msgs:
                response_lengths.append(len(assistant_msgs[0]["content"]))

        if response_lengths:
            avg = sum(response_lengths) / len(response_lengths)
            if avg < 20:
                self.issues.append({
                    "severity": "warning",
                    "message": "Assistant responses are very short on average"
                })

    def _check_language(self, data):
        """Basic language consistency check."""
        from collections import Counter
        # Simple heuristic: check if most text is ASCII
        non_ascii = 0
        for example in data:
            for msg in example.get("messages", []):
                content = msg.get("content", "")
                non_ascii_ratio = sum(
                    1 for c in content if ord(c) > 127
                ) / max(len(content), 1)
                if non_ascii_ratio > 0.3:
                    non_ascii += 1
                    break

        if non_ascii > len(data) * 0.3:
            self.issues.append({
                "severity": "info",
                "message": f"{non_ascii} examples contain significant "
                          f"non-ASCII characters"
            })
```

## Code Example: Fine-Tuning with LoRA

### Complete Training Script

```python
# fine_tune.py
# Requirements: pip install torch transformers peft datasets accelerate bitsandbytes

import torch
from datasets import load_dataset
from transformers import (
    AutoModelForCausalLM,
    AutoTokenizer,
    TrainingArguments,
    Trainer,
    BitsAndBytesConfig,
)
from peft import (
    LoraConfig,
    get_peft_model,
    prepare_model_for_kbit_training,
    TaskType,
)


def load_model(model_name: str, use_qlora: bool = True):
    """
    Load a pre-trained model with optional 4-bit quantization.

    Args:
        model_name: HuggingFace model name or path
        use_qlora: Whether to use QLoRA (4-bit quantization)
    """
    print(f"Loading model: {model_name}")

    # Quantization config for QLoRA
    if use_qlora:
        bnb_config = BitsAndBytesConfig(
            load_in_4bit=True,
            bnb_4bit_use_double_quant=True,
            bnb_4bit_quant_type="nf4",
            bnb_4bit_compute_dtype=torch.bfloat16,
        )
    else:
        bnb_config = None

    # Load model
    model = AutoModelForCausalLM.from_pretrained(
        model_name,
        quantization_config=bnb_config,
        device_map="auto",
        trust_remote_code=True,
        torch_dtype=torch.bfloat16,
    )

    # Load tokenizer
    tokenizer = AutoTokenizer.from_pretrained(
        model_name,
        trust_remote_code=True,
    )

    # Ensure tokenizer has a pad token
    if tokenizer.pad_token is None:
        tokenizer.pad_token = tokenizer.eos_token

    return model, tokenizer


def create_lora_config(
    rank: int = 16,
    alpha: int = 32,
    dropout: float = 0.05,
    target_modules: list[str] = None,
):
    """
    Create a LoRA configuration.

    Args:
        rank: LoRA rank (higher = more capacity)
        alpha: LoRA alpha scaling factor
        dropout: Dropout rate for LoRA layers
        target_modules: Which layers to apply LoRA to
    """
    if target_modules is None:
        # Common targets for most transformer models
        target_modules = [
            "q_proj", "k_proj", "v_proj", "o_proj",
            "gate_proj", "up_proj", "down_proj",
        ]

    return LoraConfig(
        task_type=TaskType.CAUSAL_LM,
        r=rank,
        lora_alpha=alpha,
        lora_dropout=dropout,
        target_modules=target_modules,
        bias="none",
        modules_to_save=None,  # Set this to ["embed_tokens", "lm_head"]
        # if you want to also train embedding layers
    )


def prepare_dataset(tokenizer, data_path: str = None, max_length: int = 2048):
    """Load and prepare the training dataset."""

    # Load your custom dataset
    # Supports JSON, JSONL, CSV, or Parquet
    if data_path:
        if data_path.endswith(".json") or data_path.endswith(".jsonl"):
            dataset = load_dataset("json", data_files=data_path)
        elif data_path.endswith(".csv"):
            dataset = load_dataset("csv", data_files=data_path)
        else:
            dataset = load_dataset(data_path)
    else:
        # Demo dataset (replace with your own data)
        demo_data = [
            {
                "messages": [
                    {"role": "system", "content": "You are a helpful coding assistant."},
                    {"role": "user", "content": "Write a Python function to find prime numbers."},
                    {"role": "assistant", "content": "Here's a Python function to find prime numbers up to n:\n\ndef is_prime(n):\n    if n < 2:\n        return False\n    for i in range(2, int(n**0.5) + 1):\n        if n % i == 0:\n            return False\n    return True\n\ndef primes_up_to(n):\n    return [x for x in range(2, n + 1) if is_prime(x)]"}
                ]
            }
        ] * 100  # Repeat for demo purposes
        dataset = {"train": demo_data}

    def format_and_tokenize(examples):
        """Format messages into model input format."""
        texts = []
        for messages in examples["messages"]:
            # Apply chat template
            text = tokenizer.apply_chat_template(
                messages,
                tokenize=False,
                add_generation_prompt=False,
            )
            texts.append(text)

        # Tokenize
        tokenized = tokenizer(
            texts,
            truncation=True,
            max_length=max_length,
            padding="max_length",
        )

        # For causal LM, labels = input_ids
        tokenized["labels"] = tokenized["input_ids"].copy()

        return tokenized

    # Process dataset
    if isinstance(dataset, dict):
        dataset = dataset["train"]

    processed_dataset = dataset.map(
        format_and_tokenize,
        batched=True,
        remove_columns=dataset.column_names,
        desc="Tokenizing",
    )

    return processed_dataset


def train(
    model_name: str = "meta-llama/Llama-3.2-3B",
    data_path: str = None,
    output_dir: str = "./output",
    num_epochs: int = 3,
    batch_size: int = 4,
    learning_rate: float = 2e-4,
    lora_rank: int = 16,
    use_qlora: bool = True,
    warmup_ratio: float = 0.1,
):
    """Run the complete fine-tuning pipeline."""

    print("=" * 60)
    print("  LLM Fine-Tuning with LoRA/QLoRA")
    print("=" * 60)

    # Step 1: Load model
    print("\n[1/5] Loading model...")
    model, tokenizer = load_model(model_name, use_qlora=use_qlora)

    if use_qlora:
        model = prepare_model_for_kbit_training(model)

    # Step 2: Configure LoRA
    print("[2/5] Configuring LoRA...")
    lora_config = create_lora_config(rank=lora_rank)
    model = get_peft_model(model, lora_config)

    # Print trainable parameters
    trainable, total = model.get_nb_trainable_parameters()
    print(f"  Trainable: {trainable:,} / {total:,} "
          f"({100 * trainable / total:.2f}%)")

    # Step 3: Prepare dataset
    print("[3/5] Preparing dataset...")
    train_dataset = prepare_dataset(tokenizer, data_path)
    print(f"  Examples: {len(train_dataset)}")

    # Step 4: Training arguments
    print("[4/5] Setting up training...")
    training_args = TrainingArguments(
        output_dir=output_dir,
        num_train_epochs=num_epochs,
        per_device_train_batch_size=batch_size,
        gradient_accumulation_steps=max(1, 16 // batch_size),
        learning_rate=learning_rate,
        warmup_ratio=warmup_ratio,
        lr_scheduler_type="cosine",
        logging_steps=10,
        save_strategy="epoch",
        bf16=True,
        optim="paged_adamw_8bit",
        gradient_checkpointing=True,
        report_to="none",  # Set to "wandb" for tracking
        max_grad_norm=0.3,
    )

    # Step 5: Train
    print("[5/5] Starting training...")
    trainer = Trainer(
        model=model,
        args=training_args,
        train_dataset=train_dataset,
        tokenizer=tokenizer,
    )

    trainer.train()

    # Save the LoRA adapter
    adapter_path = f"{output_dir}/adapter"
    model.save_pretrained(adapter_path)
    tokenizer.save_pretrained(adapter_path)

    print(f"\n✓ Training complete!")
    print(f"  Adapter saved to: {adapter_path}")
    print(f"  Trainable params: {trainable:,}")

    return model, tokenizer


def merge_and_export(adapter_path: str, base_model: str, output_path: str):
    """Merge LoRA adapter with base model for deployment."""
    from peft import PeftModel

    # Load base model
    base = AutoModelForCausalLM.from_pretrained(
        base_model,
        torch_dtype=torch.bfloat16,
        device_map="auto",
    )

    # Load LoRA adapter
    model = PeftModel.from_pretrained(base, adapter_path)

    # Merge weights
    model = model.merge_and_unload()

    # Save merged model
    model.save_pretrained(output_path)

    tokenizer = AutoTokenizer.from_pretrained(adapter_path)
    tokenizer.save_pretrained(output_path)

    print(f"Merged model saved to: {output_path}")


# ============================================================
# Run training
# ============================================================

if __name__ == "__main__":
    model, tokenizer = train(
        model_name="meta-llama/Llama-3.2-3B",
        data_path="./training_data.json",
        output_dir="./my_model",
        num_epochs=3,
        batch_size=4,
        lora_rank=16,
        use_qlora=True,
    )
```

## vLLM for Serving

### What Is vLLM?

vLLM is a high-performance serving engine for language models. It is much faster than standard HuggingFace inference because of:

- **PagedAttention** — Efficient memory management for multiple requests
- **Continuous Batching** — Process multiple requests simultaneously
- **Optimized CUDA Kernels** — Fast GPU operations

```
Standard Serving (HuggingFace):
  Request 1: ────────────────────▶ Done
  Request 2:     wait... ────────────────────────▶ Done
  Request 3:         wait...     wait... ───────────────▶ Done

vLLM Serving:
  Request 1: ────────────────▶ Done
  Request 2: ────────────────▶ Done
  Request 3: ────────────────▶ Done
  (All process in parallel!)
```

### Performance Comparison

| Metric | HuggingFace | vLLM | Improvement |
|--------|------------|------|-------------|
| Throughput (req/s) | 5 | 30-50 | 6-10x |
| Latency (p50) | 2000ms | 300ms | 6x faster |
| Latency (p99) | 8000ms | 800ms | 10x faster |
| Memory efficiency | 40% | 85% | 2x better |
| Concurrent users | 10-20 | 100+ | 5-10x |

```python
from vllm import LLM, SamplingParams


class VLLMServer:
    """Wrapper around vLLM for easy serving."""

    def __init__(
        self,
        model_name: str,
        max_model_len: int = 4096,
        gpu_memory_utilization: float = 0.9,
        tensor_parallel_size: int = 1,
    ):
        self.llm = LLM(
            model=model_name,
            max_model_len=max_model_len,
            gpu_memory_utilization=gpu_memory_utilization,
            tensor_parallel_size=tensor_parallel_size,
            dtype="bfloat16",
        )
        print(f"Model loaded: {model_name}")

    def generate(
        self,
        prompts: list[str],
        max_tokens: int = 512,
        temperature: float = 0.7,
        top_p: float = 0.9,
        stop: list[str] = None,
    ) -> list[str]:
        """
        Generate responses for one or more prompts.

        Args:
            prompts: List of input prompts
            max_tokens: Maximum tokens to generate
            temperature: Sampling temperature
            top_p: Nucleus sampling parameter
            stop: Stop sequences

        Returns:
            List of generated texts
        """
        sampling_params = SamplingParams(
            max_tokens=max_tokens,
            temperature=temperature,
            top_p=top_p,
            stop=stop,
        )

        outputs = self.llm.generate(prompts, sampling_params)

        results = []
        for output in outputs:
            generated = output.outputs[0].text
            results.append(generated)

        return results

        self,
        prompt: str,
        **kwargs
    ) -> dict:

        token_count = len(output.split())  # Approximate

        return {
            "text": output,
            "latency_ms": elapsed * 1000,
            "estimated_tokens": token_count,
            "tokens_per_second": token_count / elapsed,
```

```python
class PromptOptimizer:
    """Systematically test and optimize prompts."""

    def __init__(self, client):
        self.client = client
        self.results = []

    def add_variant(self, variant: PromptVariant):
        """Add a prompt variant to test."""
        self.results.append({
            "variant": variant,
            "scores": [],
            "latencies": [],
        })

    def evaluate(
        self,
        test_cases: list[dict],
        scoring_func: callable,
    ) -> list[dict]:
        """
        Evaluate all variants against test cases.

        Args:
            test_cases: List of {"input": ..., "expected_output": ...}
            scoring_func: Function that scores output quality (0-1)
        """
        for result in self.results:
            variant = result["variant"]
            print(f"\nTesting variant: {variant.name}")

            for i, test in enumerate(test_cases):
                # Build messages with examples
                messages = []
                if variant.examples:
                    for ex in variant.examples:
                        messages.append({"role": "user", "content": ex["input"]})
                        messages.append({"role": "assistant", "content": ex["output"]})

                messages.append({"role": "system", "content": variant.system_prompt})
                messages.append({"role": "user", "content": test["input"]})

                # Generate response
                start = time.time()
                response = self.client.chat_completion(
                    messages=messages,
                    temperature=variant.temperature,
                    max_tokens=variant.max_tokens,
                )
                latency = (time.time() - start) * 1000

                output = response["choices"][0]["message"]["content"]

                # Score the response
                score = scoring_func(output, test.get("expected_output", ""))

                result["scores"].append(score)
                result["latencies"].append(latency)

                print(f"  Test {i+1}: score={score:.2f}, latency={latency:.0f}ms")

        return self.get_rankings()

    def get_rankings(self) -> list[dict]:
        """Rank variants by average score and latency."""
        rankings = []
        for result in self.results:
            variant = result["variant"]
            avg_score = sum(result["scores"]) / len(result["scores"]) if result["scores"] else 0
            avg_latency = sum(result["latencies"]) / len(result["latencies"]) if result["latencies"] else 0

            rankings.append({
                "name": variant.name,
                "avg_score": avg_score,
                "avg_latency_ms": avg_latency,
                "total_tests": len(result["scores"]),
            })

        rankings.sort(key=lambda x: x["avg_score"], reverse=True)
        return rankings
```

## Model Evaluation Metrics

### BLEU Score

BLEU measures how similar generated text is to reference text:

```python
from collections import Counter
import math


def compute_bleu(candidate: str, reference: str, max_n: int = 4) -> float:
    """
    Compute BLEU score between candidate and reference.

    BLEU measures n-gram precision with a brevity penalty.
    Score ranges from 0 (no match) to 1 (perfect match).
    """
    import re

    # Tokenize
    cand_tokens = re.findall(r'\w+', candidate.lower())
    ref_tokens = re.findall(r'\w+', reference.lower())

    if not cand_tokens:
        return 0.0

    scores = []

    for n in range(1, max_n + 1):
        # Get n-grams
        cand_ngrams = [
            tuple(cand_tokens[i:i+n])
            for i in range(len(cand_tokens) - n + 1)
        ]
        ref_ngrams = [
            tuple(ref_tokens[i:i+n])
            for i in range(len(ref_tokens) - n + 1)
        ]

        if not cand_ngrams:
            scores.append(0)
            continue

        ref_counts = Counter(ref_ngrams)
        cand_counts = Counter(cand_ngrams)

        # Count clipped matches
        matches = 0
        for ngram, count in cand_counts.items():
            if ngram in ref_counts:
                matches += min(count, ref_counts[ngram])

        precision = matches / len(cand_ngrams) if cand_ngrams else 0
        scores.append(precision)

    # Geometric mean of precisions
    if all(s > 0 for s in scores):
        log_avg = sum(math.log(s) for s in scores) / len(scores)
        geometric_mean = math.exp(log_avg)
    else:
        geometric_mean = 0

    # Brevity penalty
    bp = min(1.0, math.exp(1 - len(ref_tokens) / max(len(cand_tokens), 1)))

    return bp * geometric_mean


# Example
candidate = "the cat sat on the mat"
reference = "the cat is sitting on the mat"
print(f"BLEU score: {compute_bleu(candidate, reference):.4f}")
```

### ROUGE Score

ROUGE measures recall-oriented overlap with reference text:

```python
def compute_rouge_l(candidate: str, reference: str) -> float:
    """
    Compute ROUGE-L score using longest common subsequence.

    ROUGE-L measures the longest common subsequence between
    candidate and reference, which captures sentence structure.
    """
    cand_tokens = candidate.lower().split()
    ref_tokens = reference.lower().split()

    # LCS length
    lcs_len = _lcs_length(cand_tokens, ref_tokens)

    if lcs_len == 0:
        return 0.0

    precision = lcs_len / len(cand_tokens) if cand_tokens else 0
    recall = lcs_len / len(ref_tokens) if ref_tokens else 0

    if precision + recall == 0:
        return 0.0

    # F1 score
    return 2 * precision * recall / (precision + recall)


def _lcs_length(x: list, y: list) -> int:
    """Compute length of longest common subsequence."""
    m, n = len(x), len(y)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if x[i-1] == y[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])

    return dp[m][n]


# Example
candidate = "The cat sat on the mat and looked around"
reference = "The cat is sitting on the mat"
print(f"ROUGE-L: {compute_rouge_l(candidate, reference):.4f}")
```

## Quantization

### What Is Quantization?

Quantization reduces the precision of model weights from 32-bit floating point to lower bit formats:

```
Original (FP32):  0.7283918261...  →  4 bytes per weight
Half (FP16):      0.7284            →  2 bytes per weight
Int8 (INT8):      186               →  1 byte per weight
Int4 (INT4):      11                →  0.5 bytes per weight

7B parameter model:
  FP32: 28 GB
  FP16: 14 GB
  INT8: 7 GB
  INT4: 3.5 GB
```

### Quantization Methods

| Method | Type | Quality | Speed | VRAM Savings |
|--------|------|---------|-------|-------------|
| **GPTQ** | Post-training | Good | Medium | 75% |
| **AWQ** | Post-training | Best | Fast | 75% |
| **GGUF** | Post-training | Good | Fast | 75% |
| **BitsAndBytes** | On-the-fly | Good | Medium | 75% |
| **GGML** | On-the-fly | Fair | Fastest | 75% |

```python
from auto_gptq import AutoGPTQForCausalLM, BaseQuantizeConfig
from transformers import AutoTokenizer


def quantize_model(
    model_path: str,
    output_path: str,
    calibration_dataset: list[str],
    bits: int = 4,
):
    """
    Quantize a model using GPTQ.

    Args:
        model_path: Path to the original model
        output_path: Path to save quantized model
        calibration_dataset: Sample texts for calibration
        bits: Number of bits (4 or 8)
    """
    # Quantization config
    quantize_config = BaseQuantizeConfig(
        bits=bits,
        group_size=128,
        damp_percent=0.01,
        desc_act=True,  # Better quality, slightly slower
    )

    # Load model and tokenizer
    model = AutoGPTQForCausalLM.from_quantized(
        model_path,
        quantize_config,
        device="cuda:0",
        use_safetensors=True,
    )
    tokenizer = AutoTokenizer.from_pretrained(model_path)

    # Prepare calibration data
    calibration_texts = [
        tokenizer(text, return_tensors="pt", max_length=2048, truncation=True)
        for text in calibration_dataset
    ]

    # Quantize
    print("Quantizing model...")
    model.quantize(calibration_texts)

    # Save
    model.save_quantized(output_path)
    tokenizer.save_pretrained(output_path)
    print(f"Quantized model saved to {output_path}")
```

## Cost Comparison: API vs Self-Hosted

### Detailed Cost Analysis

```python
def calculate_api_cost(
    requests_per_day: int,
    avg_input_tokens: int,
    avg_output_tokens: int,
    price_per_input_token: float,  # e.g., $0.003 / 1K tokens for GPT-4
    price_per_output_token: float,  # e.g., $0.006 / 1K tokens for GPT-4
) -> dict:
    """Calculate API costs."""
    daily_input_cost = (
        requests_per_day * avg_input_tokens / 1000 * price_per_input_token
    )
    daily_output_cost = (
        requests_per_day * avg_output_tokens / 1000 * price_per_output_token
    )
    daily_total = daily_input_cost + daily_output_cost

    return {
        "daily_input_cost": daily_input_cost,
        "daily_output_cost": daily_output_cost,
        "daily_total": daily_total,
        "monthly_total": daily_total * 30,
        "yearly_total": daily_total * 365,
    }


def calculate_self_hosted_cost(
    gpu_type: str,
    monthly_requests: int,
    avg_tokens_per_request: int,
) -> dict:
    """Calculate self-hosted costs."""
    # GPU hourly costs (cloud)
    gpu_costs = {
        "A100_40GB": {"hourly": 2.50, "tokens_per_sec": 3000},
        "A100_80GB": {"hourly": 4.00, "tokens_per_sec": 4000},
        "H100": {"hourly": 8.00, "tokens_per_sec": 6000},
        "RTX_4090": {"hourly": 0.50, "tokens_per_sec": 1500},
    }

    gpu = gpu_costs.get(gpu_type, gpu_costs["A100_40GB"])

    # Calculate GPU hours needed
    total_tokens = monthly_requests * avg_tokens_per_request
    total_seconds = total_tokens / gpu["tokens_per_sec"]
    total_hours = total_seconds / 3600

    # Add 30% overhead for batching and idle time
    total_hours *= 1.3

    monthly_cost = total_hours * gpu["hourly"]

    # Add base infrastructure costs
    infra_cost = 200  # Storage, networking, etc.
    monthly_total = monthly_cost + infra_cost

    return {
        "gpu_hours": total_hours,
        "gpu_monthly_cost": monthly_cost,
        "infra_monthly_cost": infra_cost,
        "monthly_total": monthly_total,
        "yearly_total": monthly_total * 12,
    }
```

## Key Takeaways

1. **API vs Self-Hosted** — Choose based on your scale, privacy needs, and budget. APIs are simpler; self-hosted gives you control.

2. **Fine-tuning** transforms a general model into a specialist. You teach it your specific task with your specific data.

3. **LoRA and QLoRA** make fine-tuning accessible. You can fine-tune a 7B model on a single consumer GPU with QLoRA.

4. **Data quality matters more than quantity.** 100 well-crafted examples beat 10,000 noisy ones.

5. **vLLM** is the standard for serving. It provides 6-10x throughput improvement over basic HuggingFace serving.

6. **Quantization** makes large models accessible. INT4 quantization reduces VRAM by 75% with minimal quality loss.

7. **Evaluation is critical.** Use BLEU, ROUGE, latency, and task-specific metrics to measure your model's performance.

8. **The pipeline approach** ensures reproducibility. Document every step from data prep to deployment.

9. **Cost analysis** should guide your architecture decisions. At scale, self-hosting becomes significantly cheaper than APIs.

10. **Start small, iterate fast.** Fine-tune a small model first, evaluate, and scale up only when needed.
