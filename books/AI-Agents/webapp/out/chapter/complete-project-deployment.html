12.1 Project Overview

What We Are Building

AgentAssist is an AI-powered customer support agent that can:

  • Answer questions from a knowledge base (RAG)
  • Look up order status via API calls (Tools)
  • Remember conversation context (Memory)
  • Escalate to a human when needed (Guardrails)
  • Run in production with monitoring and logging

User Stories

As a customer, I want to:
├── Ask questions about products and get accurate answers
├── Check my order status without calling support
├── Get help 24/7 without waiting for a human agent
└── Be transferred to a human when the AI can't help

As a support manager, I want to:
├── See all conversations and AI performance metrics
├── Know which questions the AI couldn't answer
├── Update the knowledge base without redeploying
└── Monitor costs and latency in real time

As a developer, I want to:
├── Deploy the system with one command
├── Scale horizontally when traffic increases
├── Debug issues with structured logs and traces
└── Test the system with automated evaluation

12.2 Requirements Gathering

Functional Requirements

FR-01: Chat Interface
  - Users can send messages and receive responses
  - Responses stream in real-time (WebSocket or SSE)
  - Conversation history is preserved

FR-02: Knowledge Base (RAG)
  - Agent can answer questions from uploaded documents
  - Supports PDF, Markdown, and plain text
  - Responses include source citations

FR-03: Tool Integration
  - Agent can look up order status by order ID
  - Agent can check product availability
  - Agent can create support tickets

FR-04: Escalation
  - Agent transfers to human when confidence is low
  - Full conversation context is passed to human agent

FR-05: Admin Dashboard
  - View all conversations
  - See AI performance metrics
  - Upload new documents to knowledge base

Non-Functional Requirements

NFR-01: Latency
  - First token response: < 1 second
  - Full response: < 5 seconds

NFR-02: Availability
  - 99.9% uptime
  - Graceful degradation if LLM is down

NFR-03: Security
  - All API calls authenticated (JWT)
  - No PII stored without consent
  - Rate limiting on all endpoints

NFR-04: Scalability
  - Handle 1000 concurrent conversations
  - Horizontal scaling with load balancer

Chat Endpoint

# backend/app/api/chat.py
from fastapi import APIRouter, Depends, HTTPException
from fastapi.responses import StreamingResponse
from app.schemas import ChatRequest, ChatResponse
from app.agent.core import AgentCore
from app.core.security import get_current_user
from app.config import get_settings
import time
import uuid

router = APIRouter(prefix="/api/v1/chat", tags=["chat"])

@router.post("", response_model=ChatResponse)
async def chat(
    request: ChatRequest,
    user=Depends(get_current_user),
    agent: AgentCore = Depends(),
):
    """Send a message and get a complete response."""
    start_time = time.time()

    # Create or get conversation
    conversation_id = request.conversation_id or str(uuid.uuid4())

    # Get conversation history
    history = await agent.get_history(conversation_id)

    # Process message
    result = await agent.process_message(
        message=request.message,
        history=history,
        user_id=user.id,
    )

    # Save to database
    await agent.save_message(
        conversation_id=conversation_id,
        role="user",
        content=request.message,
        user_id=user.id,
    )
    await agent.save_message(
        conversation_id=conversation_id,
        role="assistant",
        content=result["response"],
        sources=result.get("sources", []),
        tokens_used=result.get("tokens", 0),
    )

    latency_ms = (time.time() - start_time) * 1000

    return ChatResponse(
        response=result["response"],
        conversation_id=conversation_id,
        message_id=str(uuid.uuid4()),
        sources=result.get("sources", []),
        model_used=result.get("model", "unknown"),
        tokens_used=result.get("tokens", 0),
        latency_ms=latency_ms,
    )

@router.post("/stream")
async def chat_stream(
    request: ChatRequest,
    user=Depends(get_current_user),
    agent: AgentCore = Depends(),
):
    """Send a message and stream the response."""
    conversation_id = request.conversation_id or str(uuid.uuid4())

    async def event_generator():
        async for chunk in agent.stream_message(
            message=request.message,
            conversation_id=conversation_id,
            user_id=user.id,
        ):
            yield f"data: {chunk.json()}\n\n"
        yield "data: [DONE]\n\n"

    return StreamingResponse(
        event_generator(),
        media_type="text/event-stream",
    )

12.6 Step 3: Agent Core

The agent core is the brain. It decides what to do with each user message.

# backend/app/agent/core.py
from app.config import get_settings
from app.agent.prompts import SYSTEM_PROMPT, RAG_PROMPT, TOOL_PROMPT
from app.agent.memory import ConversationMemory
from app.rag.retriever import Retriever
from app.tools.order_status import OrderStatusTool
from app.tools.products import ProductSearchTool
from app.tools.tickets import TicketTool
from openai import AsyncOpenAI
import json

class AgentCore:
    def __init__(self):
        self.settings = get_settings()
        self.client = AsyncOpenAI(api_key=self.settings.OPENAI_API_KEY)
        self.memory = ConversationMemory()
        self.retriever = Retriever()
        self.tools = {
            "lookup_order": OrderStatusTool(),
            "search_products": ProductSearchTool(),
            "create_ticket": TicketTool(),
        }
        self.tool_definitions = self._build_tool_definitions()

    def _build_tool_definitions(self) -> list[dict]:
        """Convert tools to OpenAI function calling format."""
        return [
            {
                "type": "function",
                "function": {
                    "name": name,
                    "description": tool.description,
                    "parameters": tool.parameters,
                },
            }
            for name, tool in self.tools.items()
        ]

    async def process_message(
        self,
        message: str,
        history: list[dict],
        user_id: str,
    ) -> dict:
        """Process a user message and return a response."""

        # Step 1: Retrieve relevant context
        rag_context = await self.retriever.retrieve(message)

        # Step 2: Build the system prompt with context
        system = SYSTEM_PROMPT
        if rag_context:
            system += f"\n\nRelevant knowledge:\n{rag_context}"

        # Step 3: Call the LLM with tool definitions
        messages = [
            {"role": "system", "content": system},
            *history,
            {"role": "user", "content": message},
        ]

        response = await self.client.chat.completions.create(
            model=self.settings.LLM_MODEL,
            messages=messages,
            tools=self.tool_definitions,
            tool_choice="auto",
            temperature=self.settings.LLM_TEMPERATURE,
            max_tokens=self.settings.LLM_MAX_TOKENS,
        )

        assistant_message = response.choices[0].message

        # Step 4: Handle tool calls if any
        if assistant_message.tool_calls:
            return await self._handle_tool_calls(
                assistant_message,
                messages,
                user_id,
            )

        # Step 5: Return the final response
        sources = self._extract_sources(rag_context)

        return {
            "response": assistant_message.content,
            "sources": sources,
            "model": self.settings.LLM_MODEL,
            "tokens": response.usage.total_tokens,
        }

    async def _handle_tool_calls(
        self,
        assistant_message,
        messages: list[dict],
        user_id: str,
    ) -> dict:
        """Execute tool calls and continue the conversation."""
        # Add the assistant's message with tool calls
        messages.append({
            "role": "assistant",
            "content": assistant_message.content,
            "tool_calls": [
                {
                    "id": tc.id,
                    "type": "function",
                    "function": {
                        "name": tc.function.name,
                        "arguments": tc.function.arguments,
                    },
                }
                for tc in assistant_message.tool_calls
            ],
        })

        # Execute each tool call
        for tool_call in assistant_message.tool_calls:
            tool_name = tool_call.function.name
            tool_args = json.loads(tool_call.function.arguments)

            tool = self.tools.get(tool_name)
            if tool:
                result = await tool.execute(**tool_args, user_id=user_id)
            else:
                result = {"error": f"Unknown tool: {tool_name}"}

            messages.append({
                "role": "tool",
                "tool_call_id": tool_call.id,
                "content": json.dumps(result),
            })

        # Call LLM again with tool results
        final_response = await self.client.chat.completions.create(
            model=self.settings.LLM_MODEL,
            messages=messages,
            temperature=self.settings.LLM_TEMPERATURE,
            max_tokens=self.settings.LLM_MAX_TOKENS,
        )

        final_message = final_response.choices[0].message

        return {
            "response": final_message.content,
            "sources": [],
            "model": self.settings.LLM_MODEL,
            "tokens": final_response.usage.total_tokens,
        }

    def _extract_sources(self, rag_context: str) -> list[dict]:
        """Parse RAG context into structured sources."""
        if not rag_context:
            return []
        # Simple parsing - in production, track sources through retrieval
        return [{"text": rag_context[:200], "source": "knowledge_base"}]

    async def stream_message(
        self,
        message: str,
        conversation_id: str,
        user_id: str,
    ):
        """Stream response tokens to the client."""
        history = await self.memory.get_history(conversation_id)
        rag_context = await self.retriever.retrieve(message)

        system = SYSTEM_PROMPT
        if rag_context:
            system += f"\n\nRelevant knowledge:\n{rag_context}"

        messages = [
            {"role": "system", "content": system},
            *history,
            {"role": "user", "content": message},
        ]

        stream = await self.client.chat.completions.create(
            model=self.settings.LLM_MODEL,
            messages=messages,
            stream=True,
            temperature=self.settings.LLM_TEMPERATURE,
            max_tokens=self.settings.LLM_MAX_TOKENS,
        )

        async for chunk in stream:

# backend/app/rag/ingestion.py
from pathlib import Path
from app.rag.chunking import chunk_text
from app.rag.embeddings import embed_batch
from app.rag.vector_store import VectorStore
from app.config import get_settings
import fitz  # PyMuPDF

class DocumentIngestion:
    def __init__(self):
        self.settings = get_settings()
        self.vector_store = VectorStore()

    async def ingest_file(self, file_path: str, metadata: dict = None) -> dict:
        """Ingest a single file into the knowledge base."""
        path = Path(file_path)
        suffix = path.suffix.lower()

        # Extract text based on format
        if suffix == ".pdf":
            text = self._extract_pdf(file_path)
        elif suffix in (".md", ".txt"):
            text = path.read_text(encoding="utf-8")
        else:
            raise ValueError(f"Unsupported format: {suffix}")

        # Chunk the text
        chunks = chunk_text(
            text,
            chunk_size=self.settings.CHUNK_SIZE,
            chunk_overlap=self.settings.CHUNK_OVERLAP,
        )

        # Embed all chunks
        embeddings = await embed_batch(chunks)

        # Store in vector database
        chunk_metadata = [
            {
                **(metadata or {}),
                "source": str(path),
                "chunk_index": i,
                "total_chunks": len(chunks),
            }
            for i in range(len(chunks))
        ]

        ids = await self.vector_store.add(
            texts=chunks,
            embeddings=embeddings,
            metadata=chunk_metadata,
        )

        return {
            "filename": path.name,
            "chunks_created": len(chunks),
            "document_id": ids[0].split("_chunk")[0] if ids else None,
        }

    def _extract_pdf(self, file_path: str) -> str:
        """Extract text from PDF."""
        doc = fitz.open(file_path)
        text_parts = []
        for page in doc:
            text_parts.append(page.get_text())
        doc.close()
        return "\n\n".join(text_parts)

# backend/app/rag/retriever.py
from app.rag.embeddings import embed_text
from app.rag.vector_store import VectorStore
from app.config import get_settings

class Retriever:
    def __init__(self):
        self.settings = get_settings()
        self.vector_store = VectorStore()

    async def retrieve(self, query: str, top_k: int = None) -> str:
        """Retrieve relevant context for a query."""
        top_k = top_k or self.settings.RETRIEVAL_TOP_K

        # Embed the query
        query_embedding = await embed_text(query)

        # Search vector store
        results = await self.vector_store.search(
            embedding=query_embedding,
            top_k=top_k,
        )

        # Format results as context
        if not results:
            return ""

        context_parts = []
        for i, result in enumerate(results, 1):
            source = result["metadata"].get("source", "Unknown")
            text = result["text"]
            context_parts.append(
                f"[{i}] Source: {source}\n{text}"
            )

        return "\n\n".join(context_parts)

React Chat Component

// frontend/src/components/ChatWindow.tsx
import { useState, useRef, useEffect } from 'react';

interface Message {
  id: string;
  role: 'user' | 'assistant';
  content: string;
  sources?: Array<{ text: string; source: string }>;
  timestamp: Date;
}

export default function ChatWindow() {
  const [messages, setMessages] = useState<Message[]>([]);
  const [input, setInput] = useState('');
  const [isLoading, setIsLoading] = useState(false);
  const [conversationId, setConversationId] = useState<string | null>(null);
  const messagesEndRef = useRef<HTMLDivElement>(null);

  const scrollToBottom = () => {
    messagesEndRef.current?.scrollIntoView({ behavior: 'smooth' });
  };

  useEffect(scrollToBottom, [messages]);

  const sendMessage = async () => {
    if (!input.trim() || isLoading) return;

    const userMessage: Message = {
      id: crypto.randomUUID(),
      role: 'user',
      content: input,
      timestamp: new Date(),
    };

    setMessages((prev) => [...prev, userMessage]);
    setInput('');
    setIsLoading(true);

    try {
      const response = await fetch('/api/v1/chat/stream', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          Authorization: `Bearer ${getAuthToken()}`,
        },
        body: JSON.stringify({
          message: input,
          conversation_id: conversationId,
        }),
      });

      const reader = response.body?.getReader();
      const decoder = new TextDecoder();
      let assistantContent = '';

      // Create placeholder for assistant message
      const assistantId = crypto.randomUUID();
      setMessages((prev) => [
        ...prev,
        {
          id: assistantId,
          role: 'assistant',
          content: '',
          timestamp: new Date(),
        },
      ]);

      while (reader) {
        const { done, value } = await reader.read();
        if (done) break;

        const text = decoder.decode(value);
        const lines = text.split('\n');

        for (const line of lines) {
          if (line.startsWith('data: ')) {
            const data = line.slice(6);
            if (data === '[DONE]') break;

            try {
              const chunk = JSON.parse(data);
              if (chunk.type === 'token') {
                assistantContent += chunk.content;
                setMessages((prev) =>
                  prev.map((m) =>
                    m.id === assistantId
                      ? { ...m, content: assistantContent }
                      : m
                  )
                );
              } else if (chunk.type === 'sources') {
                setMessages((prev) =>
                  prev.map((m) =>
                    m.id === assistantId
                      ? { ...m, sources: chunk.sources }
                      : m
                  )
                );
              }
            } catch {
              // Skip malformed JSON
            }
          }
        }
      }

      if (!conversationId) {
        // Extract conversation ID from first response
        const idMatch = messages[messages.length - 1]?.id;
        if (idMatch) setConversationId(idMatch);
      }
    } catch (error) {
      setMessages((prev) => [
        ...prev,
        {
          id: crypto.randomUUID(),
          role: 'assistant',
          content: 'Sorry, something went wrong. Please try again.',
          timestamp: new Date(),
        },
      ]);
    } finally {
      setIsLoading(false);
    }
  };

  return (
    <div className="flex flex-col h-screen max-w-2xl mx-auto">
      {/* Header */}
      <div className="p-4 border-b bg-white shadow-sm">
        <h1 className="text-xl font-semibold">AgentAssist</h1>
        <p className="text-sm text-gray-500">
          AI-powered support · Always available
        </p>
      </div>

      {/* Messages */}
      <div className="flex-1 overflow-y-auto p-4 space-y-4">
        {messages.length === 0 && (
          <div className="text-center text-gray-400 mt-20">
            <p className="text-lg">How can I help you today?</p>
            <p className="text-sm mt-2">
              Ask about orders, products, or anything else
            </p>
          </div>
        )}

        {messages.map((msg) => (
          <div
            key={msg.id}
            className={`flex ${
              msg.role === 'user' ? 'justify-end' : 'justify-start'
            }`}
          >
            <div
              className={`max-w-[80%] rounded-lg p-3 ${
                msg.role === 'user'
                  ? 'bg-blue-600 text-white'
                  : 'bg-gray-100 text-gray-900'
              }`}
            >
              <p className="whitespace-pre-wrap">{msg.content}</p>
              {msg.sources && msg.sources.length > 0 && (
                <div className="mt-2 pt-2 border-t border-gray-200 text-xs text-gray-500">
                  <p className="font-medium">Sources:</p>
                  {msg.sources.map((s, i) => (
                    <p key={i}>📄 {s.source}</p>
                  ))}
                </div>
              )}
            </div>
          </div>
        ))}

        {isLoading && messages[messages.length - 1]?.content === '' && (
          <div className="flex justify-start">
            <div className="bg-gray-100 rounded-lg p-3">
              <div className="flex space-x-1">
                <div className="w-2 h-2 bg-gray-400 rounded-full animate-bounce" />
                <div className="w-2 h-2 bg-gray-400 rounded-full animate-bounce delay-75" />
                <div className="w-2 h-2 bg-gray-400 rounded-full animate-bounce delay-150" />
              </div>
            </div>
          </div>
        )}

        <div ref={messagesEndRef} />
      </div>

      {/* Input */}
      <div className="p-4 border-t bg-white">
        <form
          onSubmit={(e) => {
            e.preventDefault();
            sendMessage();
          }}
          className="flex gap-2"
        >
          <input
            type="text"
            value={input}
            onChange={(e) => setInput(e.target.value)}
            placeholder="Type your message..."
            className="flex-1 px-4 py-2 border rounded-lg focus:outline-none focus:ring-2 focus:ring-blue-500"
            disabled={isLoading}
          />
          <button
            type="submit"
            disabled={isLoading || !input.trim()}
            className="px-4 py-2 bg-blue-600 text-white rounded-lg hover:bg-blue-700 disabled:opacity-50"
          >
            Send
          </button>
        </form>
      </div>
    </div>
  );
}

    return [
        {"text": doc, "source": meta["source"], "score": 1 - dist}
        for doc, meta, dist in zip(
            results["documents"][0],
            results["metadatas"][0],
            results["distances"][0],
        )
    ]

# ═══════════════════════════════════════════════════════════════
#  Agent
# ═══════════════════════════════════════════════════════════════

SYSTEM_PROMPT = """You are AgentAssist, a helpful customer support agent.
Answer questions using the provided context. Be concise and cite sources.
If unsure, say so. Never make up information."""

async def agent_respond(message: str, conversation_id: str) -> dict:
    start = time.time()

    # Get history
    history = conversations.get(conversation_id, [])

    # Retrieve context
    docs = retrieve(message)
    context = "\n\n".join(
        f"[{i+1}] {d['text']}" for i, d in enumerate(docs)
    )

    messages = [
        {"role": "system", "content": SYSTEM_PROMPT + f"\n\nContext:\n{context}"},
        *history,
        {"role": "user", "content": message},
    ]

    response = await client.chat.completions.create(
        model=LLM_MODEL,
        messages=messages,
        temperature=0.1,
        max_tokens=1024,
    )

    answer = response.choices[0].message.content
    tokens = response.usage.total_tokens

    # Save to history
    history.append({"role": "user", "content": message})
    history.append({"role": "assistant", "content": answer})
    conversations[conversation_id] = history

    return {
        "response": answer,
        "sources": [{"text": d["text"][:200], "source": d["source"]} for d in docs],
        "tokens": tokens,
        "latency_ms": (time.time() - start) * 1000,
    }

# ═══════════════════════════════════════════════════════════════
#  Endpoints
# ═══════════════════════════════════════════════════════════════

class ChatRequest(BaseModel):
    message: str
    conversation_id: str | None = None

@app.post("/api/v1/chat")
async def chat(request: ChatRequest):
    conv_id = request.conversation_id or str(uuid.uuid4())
    result = await agent_respond(request.message, conv_id)
    return {**result, "conversation_id": conv_id}

@app.post("/api/v1/ingest")
async def ingest(file_path: str):
    return ingest_document(file_path)

@app.get("/health")
async def health():
    return {"status": "healthy"}

if __name__ == "__main__":

    uvicorn.run(app, host="0.0.0.0", port=8000)

12.15 Deployment Checklist

Pre-Deployment

□ All tests passing (unit + integration)
□ Environment variables configured for production
□ API keys rotated (not shared with development)
□ Database migrations applied
□ Docker images built and pushed to registry
□ Health check endpoint working
□ Structured logging configured
□ Error tracking (Sentry) configured
□ Rate limiting configured
□ CORS origins set to production domain
□ HTTPS enabled (SSL certificates)

Infrastructure

□ Load balancer configured
□ Auto-scaling rules set (min: 2, max: 10)
□ Database backups scheduled (daily)
□ Redis persistence configured
□ Vector store persistence configured
□ DNS records configured
□ CDN configured for static assets

Security

□ All secrets in environment variables (not in code)
□ JWT secret is cryptographically random
□ API keys have minimum required permissions
□ Input validation on all endpoints
□ SQL injection prevention (parameterized queries)
□ Rate limiting per user and global
□ CORS restricted to production origins
□ Content Security Policy headers set
□ Vulnerability scan completed (Trivy/Snyk)

Monitoring

□ Structured logs flowing to log aggregator
□ Metrics dashboard created
□ Alerting rules configured:
  - Error rate > 5%
  - P99 latency > 5 seconds
  - CPU > 80% sustained
  - Memory > 85%
  - LLM API errors > 1%
□ On-call rotation configured
□ Runbook for common issues documented

Post-Deployment

□ Smoke test all endpoints
□ Verify RAG retrieval quality
□ Monitor first 100 conversations
□ Check cost per conversation
□ Validate streaming responses
□ Test escalation flow end-to-end
□ Load test with expected traffic
□ Document any post-deploy issues

12.16 Key Takeaways

  1. Start with requirements, not code. Define what you are building and why before writing a single line. User stories and non-functional requirements guide every architectural decision.

  2. Architecture is layers. Separate the API gateway, agent logic, RAG engine, tools, and data storage. Each layer can be developed, tested, and scaled independently.

  3. The agent core is a router. It receives a message, decides what to do (RAG query, tool call, or direct answer), and returns a response. Keep this logic clean and testable.

  4. RAG is not just retrieval. Ingestion, chunking, embedding, retrieval, and reranking are all separate concerns. Build and optimize each one independently.

  5. Tools extend the agent's capabilities. Wrap external APIs as tools with clear descriptions and parameter schemas. The LLM decides when to use them.

  6. Streaming is essential for UX. Users expect real-time responses, not a loading spinner. Implement server-sent events from the start.

  7. Docker makes deployment reproducible. Containerize everything. Docker Compose for development, ECS/Cloud Run for production.

  8. Monitor from day one. Structured logging, Prometheus metrics, and error tracking are not optional. You cannot fix what you cannot see.

  9. Security is not a feature. JWT auth, rate limiting, input validation, and secrets management are foundational. Do not bolt them on later.

  10. Ship, then iterate. The single-file version in this chapter is a working system. Start there, then decompose into microservices as scale demands.
