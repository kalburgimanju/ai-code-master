## 1. Why Customer Support Is the Perfect First Agent

### The Business Case

```
┌──────────────────────────────────────────────────────────┐
│              CUSTOMER SUPPORT BY THE NUMBERS              │
├──────────────────────────────────────────────────────────┤
│                                                           │
│  📊 80% of support queries are repetitive                 │
│  💰 Average cost per human agent interaction: $7-$15     │
│  🤖 Average cost per AI agent interaction: $0.01-$0.10   │
│  ⏱️  Average human response time: 12-24 hours            │
│  ⚡  Average AI agent response time: < 5 seconds          │
│  😊  Customer satisfaction with AI: 70-80% (for simple    │
│     queries)                                              │
│  📈  ROI of AI support: 3-5x within first year           │
│                                                           │
└──────────────────────────────────────────────────────────┘
```

### Why It Works

| Factor | Why It's Ideal for Agents |
|--------|---------------------------|
| **High volume** | Agents handle unlimited concurrent conversations |
| **Repetitive queries** | Same 20 questions account for 80% of tickets |
| **Structured data** | FAQ, policies, and procedures are well-documented |
| **Measurable outcomes** | Resolution rate, CSAT, response time are trackable |
| **Clear escalation path** | Easy to define when humans should take over |
| **Existing knowledge base** | Most companies already have docs and FAQs |

### What a Support Agent Looks Like

```
Simple Support Agent:

Customer: "I ordered item #12345 last week and haven't 
           received it yet"

Support Agent:
  1. Classifies intent → "order_status_inquiry"
  2. Retrieves order #12345 from database
  3. Checks shipping status → "In transit, arriving tomorrow"
  4. Generates friendly response with tracking info
  5. Offers to send SMS notification

  Response: "Hi! I checked your order #12345 and it's currently 
  in transit with FedEx. You can expect delivery tomorrow 
  (Thursday) by end of day. Here's your tracking link: 
  [track]. Would you like me to send you an SMS notification 
  when it's out for delivery?"
```

### What Is Intent Classification?

```python
Intent classification for customer support.

import os

            "Where is my order?",
            "When will my package arrive?",
            "Track order #12345",

        ]
    },

            "Refund for order #5678"
        ]
    },
    "account_login": {

        "examples": [
            "I can't log in",
            "My password isn't working",
            "Account locked",
            "I forgot my password"
        ]
    },
    "tech_bug": {
        "description": "Customer reports a technical bug or issue",
        "examples": [
            "The app keeps crashing",
            "I get an error when I click submit",
            "Page won't load",
            "Feature isn't working"
        ]
    },
    "tech_howto": {
        "description": "Customer needs help using a feature",
        "examples": [
            "How do I export my data?",
            "Can you show me how to set up X?",
            "Where is the settings page?",
            "I don't know how to use this feature"
        ]
    },
    "general_info": {
        "description": "Customer asking for general information",
        "examples": [
            "What are your business hours?",
            "Do you ship internationally?",
            "What's your address?",
            "Tell me about your company"
        ]
    },
    "complaint": {
        "description": "Customer is unhappy or complaining",
        "examples": [
            "This is unacceptable",
            "I've been waiting for weeks",
            "Your service is terrible",
            "I want to speak to a manager"
        ]
    }
}


def classify_intent(message: str) -> dict:
    """
    Classify a customer message into an intent.
    Returns intent and confidence score.
    """
    
    intent_descriptions = "\n".join(
        f"- {name}: {info['description']}\n  Examples: "
        f"{', '.join(info['examples'][:2])}"
        for name, info in INTENTS.items()
    )
    
    response = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[
            {"role": "system", "content": f"""Classify customer 
            support messages into intents.
            
            Available intents:
            {intent_descriptions}
            
            Return ONLY a JSON object:
            {{
                "intent": "intent_name",
                "confidence": 0.0-1.0,
                "sub_intent": "optional more specific category"
            }}
            
            Choose the best matching intent. If unclear, use 
            "general_info" with low confidence."""},
            {"role": "user", "content": f"Classify this message:\n"
             f"\"{message}\""}
        ],
        temperature=0.0,
        response_format={"type": "json_object"}
    )
    
    import json
    result = json.loads(response.choices[0].message.content)
    return result


# Test the classifier
test_messages = [
```

### Intent Classification with Confidence Thresholds

```python
"""
Intent classification with routing logic.
"""

from dataclasses import dataclass
from enum import Enum


class Urgency(Enum):
    LOW = "low"
    MEDIUM = "medium"
    HIGH = "high"
    CRITICAL = "critical"


@dataclass
class ClassificationResult:
    intent: str
    confidence: float
    urgency: Urgency
    suggested_action: str


def classify_with_urgency(message: str, 
                          history: list[str] = None) -> ClassificationResult:
    """Classify intent with urgency assessment."""
    
    # First, classify intent
    intent_result = classify_intent(message)
    
    # Then assess urgency
    urgency_prompt = f"""Assess the urgency of this customer 
    support message.
    
    Message: "{message}"
    
    Consider:
    - Is the customer frustrated or angry?
    - Is this blocking their work/business?
    - Is there financial impact?
    - Is there a security concern?
    
    Return ONLY a JSON object:
    {{
        "urgency": "low|medium|high|critical",
        "reason": "brief explanation"
    }}"""
    
    if history:
        urgency_prompt += f"\n\nConversation history: {history[-3:]}"
    
    response = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[
            {"role": "system", "content": "Assess customer support "
             "message urgency."},
            {"role": "user", "content": urgency_prompt}
        ],
        temperature=0.0,
        response_format={"type": "json_object"}
    )
    
    import json
    urgency_result = json.loads(
        response.choices[0].message.content
    )
    
    urgency = Urgency(urgency_result["urgency"])
    
    # Determine suggested action based on intent + urgency
    action = determine_action(
        intent_result["intent"], 
        urgency,
        intent_result["confidence"]
    )
    
    return ClassificationResult(
        intent=intent_result["intent"],
        confidence=intent_result["confidence"],
        urgency=urgency,
        suggested_action=action
    )


def determine_action(
    intent: str, 
    urgency: Urgency, 
    confidence: float
) -> str:
    """Determine what action to take based on classification."""
    
    # Low confidence → escalate to human
    if confidence < 0.6:
        return "escalate_to_human"
    
    # Critical urgency → always escalate
    if urgency == Urgency.CRITICAL:
        return "escalate_to_human"
    
    # High urgency on sensitive topics → escalate
    if urgency == Urgency.HIGH and intent in [
        "billing_refund", "complaint", "account_delete"
    ]:
        return "escalate_to_human"
    
    # Map intents to actions
    action_map = {
        "order_status": "lookup_order_and_respond",
        "order_return": "initiate_return_flow",
        "order_cancel": "initiate_cancel_flow",
        "billing_refund": "initiate_refund_flow",
        "account_login": "send_password_reset",
        "tech_bug": "collect_bug_details",
        "tech_howto": "search_knowledge_base",
        "general_info": "search_knowledge_base",
        "complaint": "empathize_and_escalate",
    }
    
    return action_map.get(intent, "general_response")
```

### Escalation Rules

```python
"""
Escalation workflow for customer support agents.
"""

from dataclasses import dataclass
from enum import Enum


class EscalationReason(Enum):
    LOW_CONFIDENCE = "low_confidence"
    ANGRY_CUSTOMER = "angry_customer"
    COMPLEX_ISSUE = "complex_issue"
    SECURITY_CONCERN = "security_concern"
    LEGAL_ISSUE = "legal_issue"
    VIP_CUSTOMER = "vip_customer"
    REPEATED_FAILURE = "repeated_failure"
    FINANCIAL_DISPUTE = "financial_dispute"
    HUMAN_REQUEST = "human_requested"


@dataclass
class EscalationTicket:
    reason: EscalationReason
    priority: int  # 1-5, 5 being highest
    customer_message: str
    conversation_history: list[str]
    intent_classification: dict
    suggested_human_action: str


def should_escalate(
    message: str,
    classification: dict,
    conversation_history: list[str],
    failed_attempts: int = 0,
    customer_sentiment: str = "neutral"
) -> tuple[bool, EscalationReason | None, int]:
    """
    Determine if the conversation should be escalated 
    to a human agent.
    
    Returns:
        (should_escalate, reason, priority)
    """
    
    # Rule 1: Angry/frustrated customers
    if customer_sentiment in ["angry", "very_negative"]:
        return True, EscalationReason.ANGRY_CUSTOMER, 4
    
    # Rule 2: Low classification confidence
    if classification.get("confidence", 0) < 0.5:
        return True, EscalationReason.LOW_CONFIDENCE, 2
    
    # Rule 3: Security concerns
    security_keywords = [
        "hack", "breach", "unauthorized", "stolen",
        "compromised", "suspicious", "security"
    ]
    if any(kw in message.lower() for kw in security_keywords):
        return True, EscalationReason.SECURITY_CONCERN, 5
    
    # Rule 4: Legal threats
    legal_keywords = [
        "lawyer", "attorney", "sue", "legal action",
        "lawsuit", "legal department", "attorney general"
    ]
    if any(kw in message.lower() for kw in legal_keywords):
        return True, EscalationReason.LEGAL_ISSUE, 5
    
    # Rule 5: Financial disputes
    if classification.get("intent") == "billing_refund":
        # Check for large amounts
        import re
        amounts = re.findall(r'\$[\d,]+\.?\d*', message)
        for amount in amounts:
            value = float(amount.replace('$', '').replace(',', ''))
            if value > 500:
                return True, EscalationReason.FINANCIAL_DISPUTE, 4
    
    # Rule 6: Customer explicitly asks for human
    human_keywords = [
        "speak to a human", "talk to a person", "real agent",
        "human agent", "manager", "supervisor"
    ]
    if any(kw in message.lower() for kw in human_keywords):
        return True, EscalationReason.HUMAN_REQUEST, 3
    
    # Rule 7: Repeated failures
    if failed_attempts >= 3:
        return True, EscalationReason.REPEATED_FAILURE, 3
    
    # No escalation needed
    return False, None, 0


def create_escalation_ticket(
    message: str,
    classification: dict,
    history: list[str],
    reason: EscalationReason,
    priority: int
) -> EscalationTicket:
    """Create an escalation ticket for human agents."""
    
    # Generate suggested action for human agent
    suggestions = {
        EscalationReason.ANGRY_CUSTOMER: 
            "Start with empathy. Acknowledge frustration. "
            "Offer concrete resolution.",
        EscalationReason.COMPLEX_ISSUE: 
            "Review full conversation. May need technical "
            "expertise or special authorization.",
        EscalationReason.SECURITY_CONCERN: 
            "URGENT: Follow security incident protocol. "
            "Do not share account details in chat.",
        EscalationReason.LEGAL_ISSUE: 
            "Do not make promises. Document everything. "
            "Escalate to legal team.",
        EscalationReason.FINANCIAL_DISPUTE: 
            "Review transaction history. May need manager "
            "approval for large refunds.",
        EscalationReason.HUMAN_REQUEST: 
            "Customer explicitly requested human agent. "
            "Connect immediately.",
        EscalationReason.LOW_CONFIDENCE: 
            "AI was unable to determine customer intent. "
            "Clarify with customer.",
        EscalationReason.REPEATED_FAILURE: 
            "AI failed to resolve after multiple attempts. "
            "Review conversation and take over.",
    }
    
    return EscalationTicket(
        reason=reason,
        priority=priority,
        customer_message=message,
        conversation_history=history,
        intent_classification=classification,
        suggested_human_action=suggestions.get(
            reason, "Review and assist customer"
        )
    )
```

## 4. Knowledge Base Integration

### RAG for Customer Support

```python
"""
Customer support knowledge base with RAG.
"""

import chromadb
from openai import OpenAI
import json

client = OpenAI()


class SupportKnowledgeBase:
    """
    Knowledge base for customer support using RAG.
    """
    
    def __init__(self, db_path: str = "./support_kb"):
        self.chroma_client = chromadb.PersistentClient(path=db_path)
        self.collection = self.chroma_client.get_or_create_collection(
            name="support_docs",
            metadata={"hnsw:space": "cosine"}
        )
    
    def ingest_faq(self, faqs: list[dict]):
        """Ingest FAQ documents."""
        documents = []
        ids = []
        metadatas = []
        
        for i, faq in enumerate(faqs):
            # Combine question and answer for better retrieval
            doc = f"Q: {faq['question']}\nA: {faq['answer']}"
            documents.append(doc)
            ids.append(f"faq_{i}")
            metadatas.append({
                "type": "faq",
                "category": faq.get("category", "general"),

            metadatas.append({

                "policy_name": policy["name"],
                "category": policy.get("category", "general")
            })

            documents=documents,
            ids=ids,

        )

        self, 
        query: str, 
        n_results: int = 3,
        doc_type: str | None = None
    ) -> list[dict]:
        """Search the knowledge base."""
        query_params = {
            "query_texts": [query],
            "n_results": n_results,
            "include": ["documents", "metadatas", "distances"]
        }
        
        if doc_type:
            query_params["where"] = {"type": doc_type}
        
        results = self.collection.query(**query_params)
        
        docs = []
        for i in range(len(results["ids"][0])):
            docs.append({
                "content": results["documents"][0][i],
                "metadata": results["metadatas"][0][i],
                "relevance": 1 - results["distances"][0][i]
            })
        
        return docs
    
    def get_answer(
        self, 
        question: str, 
        customer_context: dict | None = None
    ) -> dict:
        """
        Get an answer to a customer question using RAG.
        """
        # Search for relevant documents
        relevant_docs = self.search(question, n_results=3)
        
        # Build context
        context_parts = []
        for doc in relevant_docs:
            context_parts.append(doc["content"])
        
        context = "\n\n---\n\n".join(context_parts)
        
        # Build system prompt

        agent for TechCorp.

        say you'll need to connect them with a specialist.

        - Be warm and professional
        - Use the customer's name if available
        - Be specific with numbers, dates, and policies
        - If unsure, escalate rather than guess
        
        Knowledge Base:
        {context}
        """
        
        if customer_context:
            system_prompt += f"\nCustomer Info: {json.dumps(customer_context)}"
        
        # Generate response
        response = client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[
                {"role": "system", "content": system_prompt},
                {"role": "user", "content": question}
            ],
            temperature=0.3
        )
        
        return {
            "answer": response.choices[0].message.content,
            "sources": [d["content"][:100] for d in relevant_docs],
            "confidence": relevant_docs[0]["relevance"] 
                if relevant_docs else 0
        }
```

### Managing Conversation State

```python
"""
Multi-turn conversation management for support agents.
"""

from dataclasses import dataclass, field
from datetime import datetime
from enum import Enum


class ConversationState(Enum):
    GREETING = "greeting"
    INTENT_GATHERING = "intent_gathering"
    INFORMATION_COLLECTING = "information_collecting"
    RESOLVING = "resolving"
    FOLLOW_UP = "follow_up"
    ESCALATING = "escalating"
    CLOSING = "closing"


@dataclass
class ConversationContext:
    """Maintains state across a multi-turn conversation."""
    
    customer_id: str
    customer_name: str = ""
    state: ConversationState = ConversationState.GREETING
    intent: str = ""
    confidence: float = 0.0
    entities: dict = field(default_factory=dict)
    messages: list[dict] = field(default_factory=list)
    resolution_attempts: int = 0
    max_attempts_before_escalation: int = 3
    created_at: datetime = field(default_factory=datetime.now)
    tags: list[str] = field(default_factory=list)
    
    def add_message(self, role: str, content: str):
        """Add a message to the conversation."""
        self.messages.append({
            "role": role,
            "content": content,
            "timestamp": datetime.now().isoformat()
        })
    
    def get_history_for_llm(self, max_messages: int = 10) -> list[dict]:
        """Get formatted history for API call."""
        history = [{"role": "system", "content": self._build_prompt()}]
        
        recent = self.messages[-max_messages:]
        for msg in recent:
            history.append({
                "role": msg["role"],
                "content": msg["content"]
            })
        
        return history
    
    def _build_prompt(self) -> str:
        """Build the system prompt based on conversation state."""
        base = f"""You are a helpful customer support agent.
        
Customer: {self.customer_name or 'Unknown'}
Intent: {self.intent or 'Not yet determined'}
State: {self.state.value}
Attempts to resolve: {self.resolution_attempts}

"""
        if self.state == ConversationState.GREETING:
            base += "Greet the customer warmly and ask how you "
            base += "can help."
        elif self.state == ConversationState.INTENT_GATHERING:
            base += "Ask clarifying questions to understand "
            base += "the issue."
        elif self.state == ConversationState.INFORMATION_COLLECTING:
            base += "Gather needed information (order number, "
            base += "email, etc.)."
        elif self.state == ConversationState.RESOLVING:
            base += "Provide a solution. Be specific and helpful."
        elif self.state == ConversationState.ESCALATING:
            base += "Let the customer know you're connecting "
            base += "them to a specialist."
        
        return base


class MultiTurnSupportAgent:
    """
    Support agent that manages multi-turn conversations.
    """
    
    def __init__(self):
        self.conversations: dict[str, ConversationContext] = {}
        self.kb = SupportKnowledgeBase()
        self.client = OpenAI()
    
    def start_conversation(
        self, customer_id: str, customer_name: str = ""
    ) -> str:
        """Start a new conversation."""
        ctx = ConversationContext(
            customer_id=customer_id,
            customer_name=customer_name
        )
        self.conversations[customer_id] = ctx
        
        greeting = (f"Hi{f' {customer_name}' if customer_name else ''}!"
                   f" Welcome to TechCorp support. How can I "
                   f"help you today?")
        
        ctx.add_message("assistant", greeting)
        return greeting
    
    def handle_message(
        self, customer_id: str, message: str
    ) -> str:
        """Process a customer message in an ongoing conversation."""
        
        if customer_id not in self.conversations:
            return self.start_conversation(customer_id)
        
        ctx = self.conversations[customer_id]
        ctx.add_message("user", message)
        
        # Update conversation state
        self._update_state(ctx, message)
        
        # Generate response based on state
        response = self._generate_response(ctx)
        
        ctx.add_message("assistant", response)
        return response
    
    def _update_state(
        self, ctx: ConversationContext, message: str
    ):
        """Update conversation state based on new message."""
        
        if ctx.state == ConversationState.GREETING:
            # First real message → gather intent
            ctx.state = ConversationState.INTENT_GATHERING
            classification = classify_intent(message)
            ctx.intent = classification["intent"]
            ctx.confidence = classification["confidence"]
            
        elif ctx.state == ConversationState.INTENT_GATHERING:
            # Check if we have enough info
            if ctx.confidence > 0.7:
                ctx.state = ConversationState.RESOLVING
            else:
                ctx.state = ConversationState.INFORMATION_COLLECTING
        
        elif ctx.state == ConversationState.RESOLVING:
            # Check if resolution was successful
            if self._is_resolution_satisfied(message):
                ctx.state = ConversationState.CLOSING
            else:
                ctx.resolution_attempts += 1
                if ctx.resolution_attempts >= ctx.max_attempts_before_escalation:
                    ctx.state = ConversationState.ESCALATING
    
    def _generate_response(
        self, ctx: ConversationContext
    ) -> str:
        """Generate appropriate response based on state."""
        
        messages = ctx.get_history_for_llm()
        
        response = self.client.chat.completions.create(
            model="gpt-4o-mini",
            messages=messages,
            temperature=0.3,
            max_tokens=300
        )
        
        return response.choices[0].message.content
    
    def _is_resolution_satisfied(self, message: str) -> bool:
        """Check if the customer is satisfied with the resolution."""
        satisfaction_keywords = [
            "thank you", "thanks", "perfect", "great",
            "that works", "solved", "awesome", "excellent",
            "got it", "appreciate"
        ]
        return any(kw in message.lower() for kw in satisfaction_keywords)
```

## 7. Human-in-the-Loop Patterns

### Why Human-in-the-Loop Is Essential

```
┌──────────────────────────────────────────────────────┐
│           HUMAN-IN-THE-LOOP PRINCIPLES                │
├──────────────────────────────────────────────────────┤
│                                                       │
│  1. AI Suggests, Human Decides                        │
│     AI proposes actions → Human approves before        │
│     execution for sensitive operations                 │
│                                                       │
│  2. AI Handles, Human Monitors                        │
│     AI manages conversations → Human reviews           │
│     and intervenes when needed                        │
│                                                       │
│  3. AI Triage, Human Solves                           │
│     AI collects info and classifies → Human            │
│     handles complex or sensitive cases                 │
│                                                       │
│  4. AI Drafts, Human Edits                            │
│     AI writes responses → Human reviews               │
│     before sending (high-stakes situations)           │
│                                                       │
└──────────────────────────────────────────────────────┘
```

### Implementation Pattern

```python
"""
Human-in-the-loop support agent.
"""

from dataclasses import dataclass
from datetime import datetime


@dataclass
class HumanReviewRequest:
    """Request for human review of AI action."""
    request_id: str
    conversation_id: str
    ai_response: str
    proposed_action: str | None
    reason: str
    priority: int
    created_at: datetime
    status: str = "pending"  # pending, approved, rejected
    human_notes: str = ""


class HumanInTheLoopAgent:
    """
    Support agent with human oversight.
    """
    
    def __init__(self):
        self.pending_reviews: dict[str, HumanReviewRequest] = {}
        self.review_counter = 0
    
    def _needs_human_review(
        self, 
        action: str, 
        context: dict
    ) -> bool:
        """Determine if an action needs human review."""
        
        high_risk_actions = [
            "process_refund",
            "cancel_subscription",
            "delete_account",
            "modify_order",
            "escalate_to_legal",
        ]
        
        # Always review high-risk actions
        if action in high_risk_actions:
            return True
        
        # Review if customer sentiment is very negative
        if context.get("sentiment") == "very_negative":
            return True
        
        # Review if refund amount is high
        if action == "process_refund":
            amount = context.get("refund_amount", 0)
            if amount > 200:
                return True
        
        return False
    
    def process_action(
        self,
        conversation_id: str,
        action: str,
        parameters: dict,
        ai_response: str
    ) -> dict:
        """
        Process an action with optional human review.
        """
        
        if self._needs_human_review(action, parameters):
            # Create review request
            self.review_counter += 1
            request = HumanReviewRequest(
                request_id=f"REV-{self.review_counter:04d}",
                conversation_id=conversation_id,
                ai_response=ai_response,
                proposed_action=action,
                reason=f"Action '{action}' requires human review",
                priority=self._calculate_priority(
                    action, parameters
                ),
                created_at=datetime.now()
            )
            
            self.pending_reviews[request.request_id] = request
            
            return {
                "status": "pending_review",
                "request_id": request.request_id,
                "message": "This requires approval from a specialist. "
                          "They'll review it shortly.",
                "estimated_wait": "2-5 minutes"
            }
        else:
            # Auto-approve low-risk actions
            return {
                "status": "approved",
                "message": ai_response,
                "action_executed": action
            }
    
    def _calculate_priority(
        self, action: str, parameters: dict
    ) -> int:
        """Calculate review priority (1-5)."""
        if action in ["escalate_to_legal", "security_issue"]:
            return 5
        if action == "process_refund":
            amount = parameters.get("refund_amount", 0)
            if amount > 500:
                return 5
            elif amount > 200:
                return 4
            return 3
        if action in ["cancel_subscription", "delete_account"]:
            return 4
        return 2
    
    def approve_request(
        self, request_id: str, human_notes: str = ""
    ) -> dict:
        """Approve a pending review request."""
        if request_id not in self.pending_reviews:
            return {"error": "Request not found"}
        
        request = self.pending_reviews[request_id]
        request.status = "approved"
        request.human_notes = human_notes
        
        return {
            "status": "approved",
            "request_id": request_id,
            "action": request.proposed_action,
            "notes": human_notes
        }
    
    def reject_request(
        self, request_id: str, reason: str
    ) -> dict:
        """Reject a pending review request."""
        if request_id not in self.pending_reviews:
            return {"error": "Request not found"}
        
        request = self.pending_reviews[request_id]
        request.status = "rejected"
        request.human_notes = reason
        
        return {
            "status": "rejected",
            "request_id": request_id,
            "reason": reason
        }
    
    def get_pending_reviews(
        self, min_priority: int = 1
    ) -> list[dict]:
        """Get all pending review requests."""
        pending = [
            {
                "request_id": r.request_id,
                "conversation_id": r.conversation_id,
                "action": r.proposed_action,
                "reason": r.reason,
                "priority": r.priority,
                "ai_response": r.ai_response,
                "created_at": r.created_at.isoformat()
            }
            for r in self.pending_reviews.values()
            if r.status == "pending" and r.priority >= min_priority
        ]
        
        return sorted(pending, key=lambda x: x["priority"], 
                     reverse=True)
```

```python
            "billing_refund": "initiate_refund",
            "account_login": "send_password_reset",
            "tech_bug": "log_bug_report",
            "complaint": "log_complaint",
        }
        
        action = action_map.get(intent, "general_response")
        
        # In production, these would call actual APIs
        if action == "lookup_order":
            # Extract order ID and look up
            return "Order lookup initiated"
        elif action == "initiate_return":
            return "Return process started"
        elif action == "initiate_refund":
            return "Refund request logged for review"
        
        return "General response provided"
    
    def _escalate(
        self, 
        customer_id: str,
        message: str,
        reason,
        priority: int
    ) -> dict:
        """Escalate to human agent."""
        
        escalation = {
            "customer_id": customer_id,
            "message": message,
            "reason": reason.value if reason else "unknown",
            "priority": priority,
            "timestamp": datetime.now().isoformat()
        }
        
        self.escalation_queue.append(escalation)
        
        return {
            "response": "I understand this is important to you. "
                       "I'm connecting you with a specialist who "
                       "can help right away. They'll have the full "
                       "context of our conversation.",
            "intent": "escalated",
            "sentiment": "unknown",
            "action_taken": "escalated_to_human",
            "escalated": True,
            "escalation_reason": reason.value if reason else "unknown",
            "priority": priority
        }
    
    def get_analytics(self) -> dict:
        """Get conversation analytics."""
        
        total = len(self.conversations)
        resolved = sum(
            1 for c in self.conversations.values() 
            if c.get("resolved")
        )
        escalated = len(self.escalation_queue)
        
        sentiments = {}
        intents = {}
        
        for conv in self.conversations.values():
            for msg in conv["messages"]:
                if msg.get("sentiment"):
                    s = msg["sentiment"]
                    sentiments[s] = sentiments.get(s, 0) + 1
                if msg.get("intent"):
                    i = msg["intent"]
                    intents[i] = intents.get(i, 0) + 1
        
        return {
            "total_conversations": total,
            "resolved": resolved,
            "escalated": escalated,
            "resolution_rate": f"{resolved/total*100:.1f}%" 
                if total > 0 else "N/A",
            "sentiment_distribution": sentiments,
            "intent_distribution": intents
        }
```

### Best Practices from Production Deployments

1. **Start with the top 20 FAQs**: These cover 80% of queries
2. **Always provide an escape hatch**: Easy switch to human agent
3. **Monitor and iterate**: Track resolution rates, CSAT, and escalations weekly
4. **Train on real conversations**: Use actual support transcripts for fine-tuning
5. **Set expectations**: Tell customers they're talking to AI
6. **Personalize**: Use customer name, order history, and context
7. **Follow up**: Send satisfaction surveys after resolution

## 11. Key Takeaways

1. **Customer support is the ideal first agent** — high volume, structured data, clear success metrics, and obvious ROI.

2. **Intent classification** is the foundation — accurately determining what customers want enables proper routing and handling.

3. **Escalation workflows** are critical — define clear rules for when AI should hand off to humans, especially for sensitive or complex issues.

4. **RAG-powered knowledge bases** give agents access to accurate, up-to-date information without hallucinating.

5. **Multi-turn conversations** require careful state management — track intent, entities, resolution attempts, and context across messages.

6. **Sentiment detection** enables empathetic, appropriate responses — angry customers need different treatment than happy ones.

7. **Human-in-the-loop** is essential — AI should handle routine tasks but always defer to humans for sensitive operations.

8. **Measure everything** — track resolution rate, CSAT, escalation rate, and response time to continuously improve.
