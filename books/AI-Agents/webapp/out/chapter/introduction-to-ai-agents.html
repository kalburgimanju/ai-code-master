The "Action" Difference

The defining characteristic of an agent is taking action:

User: "Book me a flight from NYC to London next Tuesday"

Chatbot:
  "I'd recommend checking Expedia or Google Flights for 
   flights from NYC to London. Prices typically range from 
   $400-$800 round trip."
  (Provides advice but CANNOT book the flight)

Agent:
  1. Searches available flights on Tuesday
  2. Filters by user preferences (economy, non-stop)
  3. Selects best option based on price and time
  4. Books the flight using the airline API
  5. Sends confirmation to user's email
  (Takes ACTION and completes the task)

2. The Agent Loop

The Core Cycle

Every AI agent operates on a fundamental loop:

                    ┌─────────────────┐
                    │                 │
                    ▼                 │
            ┌──────────────┐         │
            │   OBSERVE    │         │
            │              │         │
            │ Receive user │         │
            │ input or     │         │
            │ environment  │         │
            │ feedback     │         │
            └──────┬───────┘         │
                   │                  │
                   ▼                  │
            ┌──────────────┐         │
            │    THINK     │         │
            │              │         │
            │ Reason about │         │
            │ what to do   │         │
            │ next         │         │
            └──────┬───────┘         │
                   │                  │
                   ▼                  │
            ┌──────────────┐         │
            │     ACT      │         │
            │              │         │
            │ Execute tool │         │
            │ or generate  │         │
            │ response     │─────────┘
            └──────────────┘

         Repeat until task is complete

Step-by-Step Walkthrough

Let's trace through a real agent interaction:

User: "Find the top 3 restaurants near me and make a reservation 
       at the best one for 7pm tonight"

ITERATION 1:
  Observe: User wants restaurant recommendations + reservation
  Think:   Need to (1) find restaurants (2) pick best (3) book
  Act:     Call Google Maps API: search_restaurants(
             location="user_location", 
             cuisine="any",
             open_now=True
           )

ITERATION 2:
  Observe: Got list of 20 restaurants
  Think:   Need to filter to top 3 by rating and reviews
  Act:     Process results: filter and rank by rating + reviews
           → Top 3: [Sakura (4.8), Pasta House (4.7), 
                      Taco Loco (4.6)]

ITERATION 3:
  Observe: Have top 3 restaurants identified
  Think:   Sakura has highest rating, should book there
  Act:     Call OpenTable API: make_reservation(
             restaurant="Sakura",
             time="19:00",
             date="today",
             party_size=user.party_size
           )

ITERATION 4:
  Observe: Reservation confirmed (Confirmation #R4521)
  Think:   Task complete! Summarize for user
  Act:     Respond: "I found the top 3 restaurants: Sakura 
           (4.8★), Pasta House (4.7★), and Taco Loco (4.6★).
           I've booked a table at Sakura for 7pm tonight. 
           Confirmation #R4521. You'll receive a confirmation 
           email shortly."

The Loop in Code

"""
The fundamental agent loop pattern.
"""

from enum import Enum
from dataclasses import dataclass


class AgentState(Enum):
    """Possible states of the agent loop."""
    OBSERVING = "observing"
    THINKING = "thinking"
    ACTING = "acting"
    DONE = "done"
    ERROR = "error"


@dataclass
class AgentStep:
    """Represents one step in the agent loop."""
    iteration: int
    state: AgentState
    observation: str
    thought: str
    action: str
    action_result: str


class AgentLoop:
    """
    Base class implementing the core agent loop.
    Subclass this and override the methods for specific agents.
    """
    
    def __init__(self, name: str = "Agent"):
        self.name = name
        self.state = AgentState.OBSERVING
        self.history: list[AgentStep] = []
        self.max_iterations = 10
    
    def observe(self, input_data: str) -> str:
        """
        Process input from user or environment.
        Override this for custom observation logic.
        """
        return input_data
    
    def think(self, observation: str) -> tuple[str, str]:
        """
        Decide what action to take.
        Returns (thought, action_description).
        Override this with your LLM reasoning logic.
        """
        raise NotImplementedError("Subclass must implement think()")
    
    def act(self, action: str) -> str:
        """
        Execute the decided action.
        Returns the result of the action.
        Override this with your tool execution logic.
        """
        raise NotImplementedError("Subclass must implement act()")
    
    def is_done(self, step: AgentStep) -> bool:
        """
        Determine if the agent should stop.
        Override this for custom termination conditions.
        """
        return "DONE" in step.action_result.upper()
    
    def run(self, user_input: str) -> list[AgentStep]:
        """
        Execute the full agent loop.
        """
        self.state = AgentState.OBSERVING
        
        for iteration in range(self.max_iterations):
            # OBSERVE
            observation = self.observe(user_input)
            self.state = AgentState.THINKING
            
            # THINK
            thought, action = self.think(observation)
            self.state = AgentState.ACTING
            
            # ACT
            try:
                action_result = self.act(action)
            except Exception as e:
                action_result = f"Error: {str(e)}"
                self.state = AgentState.ERROR
            
            # Record step
            step = AgentStep(
                iteration=iteration + 1,
                state=self.state,
                observation=observation if iteration == 0 
                    else self.history[-1].action_result,
                thought=thought,
                action=action,
                action_result=action_result
            )
            self.history.append(step)
            
            # Check if done
            if self.is_done(step):
                self.state = AgentState.DONE
                break
        
        return self.history

def get_weather(location: str, unit: str = "fahrenheit") -> dict:
    """Simulated weather API call."""
    # In production, call a real weather API
    return {
        "location": location,
        "temperature": 72 if unit == "fahrenheit" else 22,
        "condition": "Sunny",
        "humidity": 45,
        "wind_speed": 8
    }


def search_database(
    query: str, 
    category: str = None, 
    max_price: float = None
) -> list[dict]:
    """Simulated database search."""
    # In production, query your actual database
    products = [
        {"name": "Wireless Headphones", "price": 79.99, 
         "category": "electronics"},
        {"name": "Running Shoes", "price": 129.99, 
         "category": "footwear"},
        {"name": "Coffee Maker", "price": 49.99, 
         "category": "kitchen"},
    ]
    
    results = [
        p for p in products
        if query.lower() in p["name"].lower()
        and (not category or p["category"] == category)
        and (not max_price or p["price"] <= max_price)
    ]
    return results


# Map function names to actual implementations
available_functions = {
    "get_weather": get_weather,
    "search_database": search_database,
}


def run_agent(user_message: str) -> str:
    """
    Run the agent with tool use.
    Handles the full observe-think-act loop.
    """
    messages = [
        {"role": "system", "content": "You are a helpful assistant "
         "with access to weather and product search tools."},
        {"role": "user", "content": user_message}
    ]
    
    # Agent loop: keep going until no more tool calls needed
    while True:
        response = client.chat.completions.create(
            model="gpt-4o",
            messages=messages,
            tools=tools,
            tool_choice="auto"  # Let model decide when to use tools
        )
        
        response_message = response.choices[0].message
        
        # If no tool calls, return the text response
        if not response_message.tool_calls:
            return response_message.content
        
        # Process tool calls
        messages.append(response_message)
        
        for tool_call in response_message.tool_calls:
            function_name = tool_call.function.name
            function_args = json.loads(
                tool_call.function.arguments
            )
            
            print(f"  Tool: {function_name}({function_args})")
            
            # Execute the function
            function_result = available_functions[function_name](
                **function_args
            )
            
            # Add tool result to messages
            messages.append({
                "tool_call_id": tool_call.id,
                "role": "tool",
                "name": function_name,
                "content": json.dumps(function_result)
            })
    
    return "Max iterations reached"


# === Test the agent ===
print("Agent:", run_agent(
    "What's the weather in London? And do you have any electronics "
    "under $100?"
))

def run_claude_agent(user_message: str) -> str:
    """Run agent using Claude's tool use."""
    
    messages = [{"role": "user", "content": user_message}]
    
    while True:
        # Call Claude
        response = client.messages.create(
            model="claude-sonnet-4-20250514",
            max_tokens=1024,
            tools=tools,
            messages=messages
        )
        
        # Check if Claude wants to use a tool
        if response.stop_reason == "tool_use":
            # Process tool calls
            tool_results = []
            
            for block in response.content:
                if block.type == "tool_use":
                    print(f"  Claude calls: {block.name}"
                          f"({block.input})")
                    
                    # Execute tool
                    result = get_weather(**block.input)
                    
                    tool_results.append({
                        "type": "tool_result",
                        "tool_use_id": block.id,
                        "content": json.dumps(result)
                    })
            
            # Add to conversation and continue
            messages.append({"role": "assistant", 
                           "content": response.content})
            messages.append({"role": "user", 
                           "content": tool_results})
        else:
            # No more tool use - return final response
            return response.content[0].text
    
    return "Max iterations reached"

Short-Term Memory (Conversation Buffer)

"""
Short-term memory: managing conversation history.
"""

from collections import deque


class ConversationMemory:
    """
    Manages conversation history within context window limits.
    """
    
    def __init__(self, max_messages: int = 20, 
                 system_prompt: str = ""):
        self.max_messages = max_messages
        self.system_prompt = system_prompt
        self.messages: deque = deque(maxlen=max_messages)
    
    def add_message(self, role: str, content: str):
        """Add a message to the conversation."""
        self.messages.append({"role": role, "content": content})
    
    def get_messages(self) -> list[dict]:
        """Get messages for API call."""
        result = []
        if self.system_prompt:
            result.append({
                "role": "system", 
                "content": self.system_prompt
            })
        result.extend(list(self.messages))
        return result
    
    def summarize_old_messages(self, keep_recent: int = 10) -> str:
        """
        Summarize older messages to save context space.
        Useful when conversation gets very long.
        """
        if len(self.messages) <= keep_recent:
            return ""
        
        old_messages = list(self.messages)[:-keep_recent]
        
        # In production, use LLM to summarize
        summary = "Previous conversation summary: "
        summary += f"Discussed {len(old_messages)} messages about "
        topics = set()
        for msg in old_messages:
            if msg["role"] == "user":
                topics.add(msg["content"][:50])
        summary += ", ".join(list(topics)[:3])
        
        return summary
    
    def clear(self):
        """Clear conversation history."""
        self.messages.clear()


# Usage
memory = ConversationMemory(
    max_messages=20,
    system_prompt="You are a helpful coding assistant."
)

# Simulate a conversation

memory.add_message("assistant", "Use sorted() or list.sort().")
memory.add_message("user", "What about sorting dictionaries?")
memory.add_message("assistant", 
    "Use sorted(d.items(), key=lambda x: x[1]).")

# Get messages for API call

print(f"Messages in context: {len(api_messages)}")

Long-Term Memory (Vector Store)

"""
Long-term memory: persistent knowledge across sessions.
"""

from chromadb import Client
from datetime import datetime


class LongTermMemory:
    """
    Persistent memory using vector database.
    Stores important information for future retrieval.
    """
    
    def __init__(self, db_path: str = "./agent_memory"):
        self.client = Client(path=db_path)
        self.collection = self.client.get_or_create_collection(
            name="long_term_memory"
        )
    
    def store(
        self, 
        content: str, 
        memory_type: str = "fact",
        metadata: dict | None = None
    ):
        """Store a piece of information."""
        entry_metadata = {
            "type": memory_type,
            "timestamp": datetime.now().isoformat(),
            **(metadata or {})
        }
        
        # Generate unique ID
        entry_id = f"mem_{datetime.now().timestamp()}"
        
        self.collection.add(
            ids=[entry_id],
            documents=[content],
            metadatas=[entry_metadata]
        )
    
    def recall(
        self, 
        query: str, 
        n_results: int = 5,
        memory_type: str | None = None
    ) -> list[dict]:
        """Recall relevant memories."""
        query_params = {
            "query_texts": [query],
            "n_results": n_results
        }
        
        if memory_type:
            query_params["where"] = {"type": memory_type}
        
        results = self.collection.query(**query_params)
        
        memories = []
        for i in range(len(results["ids"][0])):
            memories.append({
                "content": results["documents"][0][i],
                "metadata": results["metadatas"][0][i],
                "relevance": 1 - results["distances"][0][i]
            })
        
        return memories
    
    def store_user_preference(self, preference: str):
        """Store a user preference."""
        self.store(
            content=preference,
            memory_type="preference",
            metadata={"category": "user_preference"}
        )
    
    def store_task_outcome(
        self, task: str, outcome: str, success: bool
    ):
        """Store the outcome of a task for future reference."""
        self.store(
            content=f"Task: {task}\nOutcome: {outcome}",
            memory_type="task_outcome",
            metadata={
                "success": success,
                "category": "task_history"
            }
        )
    
    def get_user_preferences(self) -> list[str]:
        """Retrieve all stored user preferences."""
        results = self.collection.query(
            query_texts=["user preferences"],
            n_results=100,
            where={"type": "preference"}
        )
        return results["documents"][0] if results["documents"] else []


# Usage
memory = LongTermMemory()

# Store preferences
memory.store_user_preference(
    "User prefers dark mode in all applications"
)
memory.store_user_preference(
    "User's timezone is PST (UTC-8)"
)
memory.store_user_preference(
    "User prefers concise responses under 100 words"
)

# Store task outcomes
memory.store_task_outcome(
    task="Deploy web app to AWS",
    outcome="Successfully deployed using ECS Fargate",
    success=True
)

# Recall memories

for mem in relevant:
    print(f"  [{mem['relevance']:.2f}] {mem['content']}")

Working Memory (Scratchpad)

"""
Working memory: intermediate state for current task.
"""

from dataclasses import dataclass, field


@dataclass
class WorkingMemory:
    """
    Temporary storage for the current task.
    Acts as a scratchpad for the agent's reasoning.
    """
    
    task_description: str = ""
    plan: list[str] = field(default_factory=list)
    current_step: int = 0
    intermediate_results: dict = field(default_factory=dict)
    errors: list[str] = field(default_factory=list)
    notes: list[str] = field(default_factory=list)
    
    def add_plan_step(self, step: str):
        """Add a step to the plan."""
        self.plan.append(step)
    
    def record_result(self, key: str, value):
        """Store an intermediate result."""
        self.intermediate_results[key] = value
    
    def record_error(self, error: str):
        """Record an error for debugging."""
        self.errors.append(error)
    
    def add_note(self, note: str):
        """Add a scratch note."""
        self.notes.append(note)
    
    def get_summary(self) -> str:
        """Get a summary of current working state."""
        summary_parts = [
            f"Task: {self.task_description}",
            f"Progress: Step {self.current_step + 1}/"
            f"{len(self.plan)}",
            f"Current plan: {self.plan[self.current_step] if self.plan else 'None'}",
            f"Results so far: {list(self.intermediate_results.keys())}",
        ]
        if self.errors:
            summary_parts.append(f"Errors: {len(self.errors)}")
        return "\n".join(summary_parts)


# Usage in agent loop

# Record progress

working.record_result("row_count", 10000)
working.record_result("date_range", "2024-01-01 to 2024-12-31")

Plan-and-Execute Pattern

"""
Plan-and-Execute agent pattern.
First creates a plan, then executes each step.
"""

from openai import OpenAI
import json

client = OpenAI()


def create_plan(task: str) -> list[str]:
    """Create a step-by-step plan for a task."""
    
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[
            {"role": "system", "content": """You are a task planner.
            Given a task, create a step-by-step plan.
            
            Return ONLY a JSON array of step descriptions.
            Each step should be specific and actionable.
            
            Example: ["Step 1 description", "Step 2 description"]"""},
            {"role": "user", "content": f"Create a plan for: {task}"}
        ],
        temperature=0.0,
        response_format={"type": "json_object"}
    )
    
    result = json.loads(response.choices[0].message.content)
    return result.get("steps", result.get("plan", []))


def execute_step(
    step: str, 
    context: dict
) -> str:
    """Execute a single step of the plan."""
    
    context_str = json.dumps(context, indent=2)
    
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[
            {"role": "system", "content": f"""Execute this step of 
            a plan. Use the provided context from previous steps.
            
            Context from previous steps:
            {context_str}
            
            Provide the specific output for this step."""},
            {"role": "user", "content": f"Execute: {step}"}
        ],
        temperature=0.2
    )
    
    return response.choices[0].message.content


def plan_and_execute(task: str) -> dict:
    """
    Complete plan-and-execute agent.
    """
    # Step 1: Create plan
    print(f"Task: {task}")
    print("=" * 50)
    
    plan = create_plan(task)
    print(f"\nPlan ({len(plan)} steps):")
    for i, step in enumerate(plan, 1):
        print(f"  {i}. {step}")
    
    # Step 2: Execute each step
    context = {}
    results = []
    
    for i, step in enumerate(plan, 1):
        print(f"\n--- Executing Step {i} ---")
        print(f"  {step}")
        
        result = execute_step(step, context)
        results.append({
            "step": i,
            "description": step,
            "result": result
        })
        
        context[f"step_{i}"] = result
        print(f"  Result: {result[:100]}...")
    
    return {
        "task": task,
        "plan": plan,
        "results": results
    }


# Usage
output = plan_and_execute(
    "Analyze our website's user engagement metrics for last month "
    "and create a 5-slide presentation outline with key findings"
)

7. Architecture Patterns

ReAct (Reasoning + Acting)

The most popular agent pattern. Combines reasoning traces with actions.

Thought: I need to find the population of France
Action: search("population of France 2024")
Observation: France has approximately 68.4 million people
Thought: Now I need to compare it to Germany
Action: search("population of Germany 2024")  
Observation: Germany has approximately 84.5 million people
Thought: I have both numbers, I can now answer
Action: respond("Germany (84.5M) has a larger population than 
France (68.4M)")

Plan-and-Execute

Create a plan first, then execute each step.

Step 1: PLANNING
  User: "Create a marketing campaign for our new product"
  
  Plan:
  1. Research target audience
  2. Analyze competitor campaigns
  3. Develop key messaging
  4. Create content calendar
  5. Draft campaign assets
  6. Review and finalize

Step 2: EXECUTION
  Execute step 1 → results
  Execute step 2 → results
  Execute step 3 → results
  ...

Reflexion

Agent reflects on its own performance and improves.

Attempt 1:
  Action: Wrote code to solve the problem
  Result: Test failed - off-by-one error

Reflection: I made an indexing mistake. I need to be more careful
with boundary conditions. Let me review the test cases first.

Attempt 2:
  Action: Reviewed test cases, rewrote code with careful indexing
  Result: All tests pass!

Reflection: Success! The key was reviewing expectations before coding.

Complete ReAct Agent from Scratch

"""
A complete ReAct agent built from scratch.
No frameworks - just OpenAI API + Python.
"""

import json
import os
from openai import OpenAI
from datetime import datetime


class SimpleAgent:
    """
    A ReAct (Reasoning + Acting) agent built from scratch.
    
    Features:
    - Tool use with automatic execution
    - Conversation memory
    - Error handling
    - Step logging
    """
    
    def __init__(
        self, 
        model: str = "gpt-4o",
        system_prompt: str | None = None,
        max_iterations: int = 10
    ):
        self.client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))
        self.model = model
        self.max_iterations = max_iterations
        self.messages = []
        self.tools = {}
        self.tool_schemas = []
        self.step_log = []
        
        # Set default system prompt
        if system_prompt is None:
            system_prompt = (
                "You are a helpful AI assistant with access to "
                "tools. Use tools when needed to complete tasks. "
                "Think step by step before acting."
            )
        
        self.messages.append({
            "role": "system", 
            "content": system_prompt
        })
    
    def register_tool(
        self, 
        name: str, 
        description: str,
        parameters: dict,
        function: callable
    ):
        """Register a tool the agent can use."""
        self.tools[name] = function
        self.tool_schemas.append({
            "type": "function",
            "function": {
                "name": name,
                "description": description,
                "parameters": parameters
            }
        })
    
    def think(self, user_input: str) -> str:
        """
        Core reasoning loop: observe, think, act.
        Returns the final response.
        """
        self.messages.append({
            "role": "user", 
            "content": user_input
        })
        
        for iteration in range(self.max_iterations):
            # Call LLM
            kwargs = {
                "model": self.model,
                "messages": self.messages,
                "temperature": 0.2
            }
            
            if self.tool_schemas:
                kwargs["tools"] = self.tool_schemas
                kwargs["tool_choice"] = "auto"
            
            response = self.client.chat.completions.create(**kwargs)
            assistant_message = response.choices[0].message
            
            # Log the step
            self.step_log.append({
                "iteration": iteration + 1,
                "model": self.model,
                "tool_calls": len(
                    assistant_message.tool_calls or []
                ),
                "timestamp": datetime.now().isoformat()
            })
            
            # If no tool calls, return the text response
            if not assistant_message.tool_calls:
                self.messages.append({
                    "role": "assistant",
                    "content": assistant_message.content
                })
                return assistant_message.content
            
            # Process tool calls
            self.messages.append({
                "role": "assistant",
                "content": assistant_message.content,
                "tool_calls": [
                    {
                        "id": tc.id,
                        "type": "function",
                        "function": {
                            "name": tc.function.name,
                            "arguments": tc.function.arguments
                        }
                    }
                    for tc in assistant_message.tool_calls
                ]
            })
            
            for tool_call in assistant_message.tool_calls:
                name = tool_call.function.name
                args = json.loads(tool_call.function.arguments)
                
                print(f"  [Tool] {name}({json.dumps(args)[:80]})")
                
                # Execute the tool
                try:
                    result = self.tools[name](**args)
                    result_str = json.dumps(result) if isinstance(
                        result, (dict, list)
                    ) else str(result)
                except Exception as e:
                    result_str = f"Error: {str(e)}"
                    print(f"  [Error] {name}: {e}")
                
                self.messages.append({
                    "role": "tool",
                    "tool_call_id": tool_call.id,
                    "content": result_str
                })
        
        return "I've reached the maximum number of steps."
    
    def reset(self):
        """Clear conversation history."""
        self.messages = [self.messages[0]]  # Keep system prompt
        self.step_log.clear()
    
    def get_stats(self) -> dict:
        """Get statistics about the conversation."""
        return {
            "total_steps": len(self.step_log),
            "total_tool_calls": sum(
                s["tool_calls"] for s in self.step_log
            ),
            "total_messages": len(self.messages),
            "model": self.model
        }

9. Building an Agent with Memory

Agent with Full Memory Integration

"""
Agent with short-term, long-term, and working memory.
"""

import json
import os
from datetime import datetime
from openai import OpenAI


class MemoryAgent:
    """
    AI Agent with three types of memory:
    1. Short-term: conversation buffer
    2. Long-term: persistent vector store
    3. Working: scratchpad for current task
    """
    
    def __init__(self, model: str = "gpt-4o"):
        self.client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))
        self.model = model
        
        # Memory systems
        self.conversation_history = []  # Short-term
        self.long_term_store = []       # Simplified vector store
        self.working_memory = {}        # Scratchpad
        
        # Tools
        self.tools = {}
        self.tool_schemas = []
    
    def _search_long_term(self, query: str, k: int = 3) -> list[str]:
        """Simple similarity search in long-term memory."""
        if not self.long_term_store:
            return []
        
        # Simple keyword matching (replace with real embedding 
        # search in production)
        results = []
        query_words = set(query.lower().split())
        
        for entry in self.long_term_store:
            entry_words = set(entry["content"].lower().split())
            overlap = len(query_words & entry_words)
            if overlap > 0:
                results.append((overlap, entry["content"]))
        
        results.sort(reverse=True, key=lambda x: x[0])
        return [content for _, content in results[:k]]
    
    def _store_long_term(self, content: str, 
                          category: str = "general"):
        """Store information in long-term memory."""
        self.long_term_store.append({
            "content": content,
            "category": category,
            "timestamp": datetime.now().isoformat()
        })
    
    def _build_context(self, user_input: str) -> str:
        """Build context from all memory sources."""
        context_parts = []
        
        # Add relevant long-term memories
        relevant = self._search_long_term(user_input)
        if relevant:
            context_parts.append(
                "Relevant memories:\n" + 
                "\n".join(f"- {m}" for m in relevant)
            )
        
        # Add working memory if available
        if self.working_memory:
            context_parts.append(
                "Current task context:\n" + 
                json.dumps(self.working_memory, indent=2)
            )
        
        return "\n\n".join(context_parts)
    
    def think(self, user_input: str) -> str:
        """Process user input through the agent loop."""
        
        # Build context from memories
        context = self._build_context(user_input)
        
        # Add user message with context
        if context:
            enhanced_input = (
                f"{user_input}\n\n"
                f"[Context from memory]:\n{context}"
            )
        else:
            enhanced_input = user_input
        
        self.conversation_history.append({
            "role": "user", 
            "content": enhanced_input
        })
        
        # Build messages for API call
        messages = [
            {"role": "system", "content": (
                "You are a helpful assistant with memory. "
                "Remember important facts about the user. "
                "Use the [context from memory] when relevant."
            )},
            *self.conversation_history[-10:]  # Last 10 messages
        ]
        
        # Call LLM
        response = self.client.chat.completions.create(
            model=self.model,
            messages=messages,
            temperature=0.3
        )
        
        assistant_response = response.choices[0].message.content
        
        self.conversation_history.append({
            "role": "assistant",
            "content": assistant_response
        })
        
        # Extract and store important information
        self._extract_and_store(user_input, assistant_response)
        
        return assistant_response
    
    def _extract_and_store(self, user_input: str, 
                           response: str):
        """Automatically extract important info to long-term memory."""
        
        # Simple heuristic: store if user shares personal info
        personal_keywords = [
            "my name is", "i live in", "i work at",
            "i prefer", "i like", "i don't like",
            "my favorite", "i need"
        ]
        
        for keyword in personal_keywords:
            if keyword in user_input.lower():
                self._store_long_term(
                    user_input, category="user_info"
                )
                break
    
    def learn(self, fact: str, category: str = "learned"):
        """Explicitly learn and store a fact."""
        self._store_long_term(fact, category)
        return f"Learned: {fact}"
    
    def recall(self, query: str) -> list[str]:
        """Search long-term memories."""
        return self._search_long_term(query)
    
    def set_task(self, task: str):
        """Set the current task in working memory."""
        self.working_memory["task"] = task
        self.working_memory["started"] = (
            datetime.now().isoformat()
        )
    
    def update_task(self, **kwargs):
        """Update working memory for current task."""
        self.working_memory.update(kwargs)
    
    def forget_conversation(self):
        """Clear short-term memory."""
        self.conversation_history.clear()

10. Key Takeaways

  1. Agents differ from chatbots in their ability to take actions — they don't just answer questions, they solve problems by using tools and interacting with external systems.

  2. The Agent Loop (Observe → Think → Act → Repeat) is the fundamental pattern behind all AI agents.

  3. Tool Use / Function Calling extends agents beyond text generation. OpenAI, Claude, and other providers all support structured tool calling.

  4. Memory Systems give agents the ability to remember:

    • Short-term: Conversation history
    • Long-term: Persistent knowledge
    • Working: Task-specific scratchpad

  5. Planning enables agents to handle complex, multi-step tasks by breaking them into manageable pieces.

  6. Architecture Patterns (ReAct, Plan-and-Execute, Reflexion) provide proven templates for building effective agents.

  7. Agent Frameworks (LangChain, CrewAI, etc.) provide ready-made infrastructure but understanding the underlying patterns is essential.

  8. Build from scratch first, then adopt frameworks — you'll understand what's happening under the hood.

  • Keeps a log of attempts and what went wrong
