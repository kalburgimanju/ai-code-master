Chapter 14: Observability & Scalability

Monitoring, Scaling, and Optimizing Agent Systems

"You cannot optimize what you cannot measure. You cannot trust what you cannot see."

Building an agent is step one. Running it in production is step two. Knowing what it is doing and why is step three — and it is the step most teams skip until something breaks at 3 AM.

Observability is the ability to understand the internal state of your system by examining its external outputs. For AI agents, this means tracking every decision, every token, every dollar, and every failure in real time.

Scalability is the ability to handle increasing load without degrading performance. For agents, this means handling 10 users or 10,000 users with the same reliability.

This chapter covers both, with practical code you can add to your agents today.

Why AI Agents Are Hard to Monitor

AI agents are harder to monitor than traditional software:

Traditional SoftwareAI Agent
Deterministic outputsNon-deterministic outputs
Same input = same outputSame input = different outputs
Clear error types"Wrong but plausible" answers
Fixed latencyVariable latency (LLM calls)
Predictable costsUnpredictable token usage
Simple request/responseMulti-step reasoning chains

Structured Logging Implementation

"""Production-grade structured logging for AI agents."""

import structlog
import time
import uuid
from contextlib import contextmanager
from dataclasses import dataclass, field
from typing import Any

def setup_logging(log_level: str = "INFO"):
    """Configure structured logging."""
    structlog.configure(
        processors=[
            structlog.contextvars.merge_contextvars,
            structlog.processors.add_log_level,
            structlog.processors.TimeStamper(fmt="iso"),
            structlog.processors.StackInfoRenderer(),
            structlog.processors.format_exc_info,
            structlog.processors.JSONRenderer(),
        ],
        wrapper_class=structlog.make_filtering_bound_logger(
            getattr(__import__("logging"), log_level.upper())
        ),
        context_class=dict,
        logger_factory=structlog.PrintLoggerFactory(),
        cache_logger_on_first_use=True,
    )

logger = structlog.get_logger()

@dataclass
class AgentTrace:
    """Trace a single agent interaction."""
    request_id: str = field(default_factory=lambda: str(uuid.uuid4())[:12])
    user_id: str = ""
    start_time: float = field(default_factory=time.time)

    # RAG
    rag_chunks_retrieved: int = 0
    rag_top_score: float = 0.0
    rag_latency_ms: float = 0.0

    # LLM
    llm_model: str = ""
    llm_prompt_tokens: int = 0
    llm_completion_tokens: int = 0
    llm_latency_ms: float = 0.0
    llm_cost_usd: float = 0.0

    # Tools
    tool_calls: list[dict] = field(default_factory=list)

    # Output
    response_length: int = 0
    sources_cited: int = 0
    total_latency_ms: float = 0.0

    # Errors
    errors: list[dict] = field(default_factory=list)
    guardrail_triggers: list[str] = field(default_factory=list)

    def log_start(self):
        logger.info(
            "agent_request_started",
            request_id=self.request_id,
            user_id=self.user_id,
        )

    def log_rag(self, chunks: int, top_score: float, latency_ms: float):
        self.rag_chunks_retrieved = chunks
        self.rag_top_score = top_score
        self.rag_latency_ms = latency_ms
        logger.info(
            "rag_retrieval",
            request_id=self.request_id,
            chunks=chunks,
            top_score=f"{top_score:.3f}",
            latency_ms=f"{latency_ms:.0f}",
        )
        if top_score < 0.5:
            logger.warning(
                "low_retrieval_score",
                request_id=self.request_id,
                score=f"{top_score:.3f}",
                message="Retrieval quality is below threshold",
            )

    def log_llm(self, model: str, prompt_tokens: int, completion_tokens: int,
                latency_ms: float, cost_usd: float):
        self.llm_model = model
        self.llm_prompt_tokens = prompt_tokens
        self.llm_completion_tokens = completion_tokens
        self.llm_latency_ms = latency_ms
        self.llm_cost_usd = cost_usd
        logger.info(
            "llm_call",
            request_id=self.request_id,
            model=model,
            prompt_tokens=prompt_tokens,
            completion_tokens=completion_tokens,
            latency_ms=f"{latency_ms:.0f}",
            cost_usd=f"{cost_usd:.6f}",
        )

    def log_tool(self, tool_name: str, params: dict, result: str,
                 latency_ms: float, success: bool):
        self.tool_calls.append({
            "tool": tool_name,
            "latency_ms": latency_ms,
            "success": success,
        })
        logger.info(
            "tool_call",
            request_id=self.request_id,
            tool=tool_name,
            params=str(params)[:200],
            result_preview=result[:100] if result else "",
            latency_ms=f"{latency_ms:.0f}",
            success=success,
        )
        if not success:
            logger.error(
                "tool_call_failed",
                request_id=self.request_id,
                tool=tool_name,
                params=str(params)[:200],
            )

    def log_error(self, error_type: str, message: str):
        self.errors.append({"type": error_type, "message": message})
        logger.error(
            "agent_error",
            request_id=self.request_id,
            error_type=error_type,
            message=message,
        )

    def log_completion(self, response_length: int, sources_cited: int):
        total_ms = (time.time() - self.start_time) * 1000
        self.total_latency_ms = total_ms
        self.response_length = response_length
        self.sources_cited = sources_cited

        total_cost = self.llm_cost_usd
        for tool in self.tool_calls:
            total_cost += tool.get("cost_usd", 0)

        logger.info(
            "agent_request_completed",
            request_id=self.request_id,
            total_latency_ms=f"{total_ms:.0f}",
            llm_latency_ms=f"{self.llm_latency_ms:.0f}",
            rag_latency_ms=f"{self.rag_latency_ms:.0f}",
            total_tokens=self.llm_prompt_tokens + self.llm_completion_tokens,
            total_cost_usd=f"{total_cost:.6f}",
            tool_calls=len(self.tool_calls),
            errors=len(self.errors),
            response_length=response_length,
            sources_cited=sources_cited,
        )

Using the Trace

async def process_message_with_trace(message: str, user_id: str) -> dict:
    """Process a message with full observability."""
    trace = AgentTrace(user_id=user_id)
    trace.log_start()

    try:
        # RAG retrieval
        start = time.time()
        docs = await retriever.retrieve(message)
        rag_latency = (time.time() - start) * 1000
        top_score = docs[0]["score"] if docs else 0
        trace.log_rag(chunks=len(docs), top_score=top_score, latency_ms=rag_latency)

        # LLM call
        start = time.time()
        response = await llm.generate(
            query=message,
            context=docs,
            model="gpt-4o",
        )
        llm_latency = (time.time() - start) * 1000

        cost = calculate_cost(
            model="gpt-4o",
            prompt_tokens=response.usage.prompt_tokens,
            completion_tokens=response.usage.completion_tokens,
        )
        trace.log_llm(
            model="gpt-4o",
            prompt_tokens=response.usage.prompt_tokens,
            completion_tokens=response.usage.completion_tokens,
            latency_ms=llm_latency,
            cost_usd=cost,
        )

        # Completion
        trace.log_completion(
            response_length=len(response.text),
            sources_cited=len(docs),
        )

        return {"response": response.text, "trace_id": trace.request_id}

    except Exception as e:
        trace.log_error(type(e).__name__, str(e))
        raise

Implementation with OpenTelemetry

"""Distributed tracing with OpenTelemetry."""

from opentelemetry import trace
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import BatchSpanProcessor
from opentelemetry.exporter.otlp.proto.grpc.trace_exporter import OTLPSpanExporter
from opentelemetry.sdk.resources import Resource

# Setup
resource = Resource.create({"service.name": "agent-assist"})
provider = TracerProvider(resource=resource)
exporter = OTLPSpanExporter(endpoint="http://localhost:4317")
provider.add_span_processor(BatchSpanProcessor(exporter))
trace.set_tracer_provider(provider)

tracer = trace.get_tracer("agent-assist")

# Usage
async def process_message(message: str) -> dict:
    with tracer.start_as_current_span("process_message") as span:
        span.set_attribute("user.message_length", len(message))

        # RAG retrieval
        with tracer.start_as_current_span("rag_retrieval") as rag_span:
            docs = await retriever.retrieve(message)
            rag_span.set_attribute("rag.chunks_found", len(docs))
            if docs:
                rag_span.set_attribute("rag.top_score", docs[0]["score"])

        # LLM call
        with tracer.start_as_current_span("llm_call") as llm_span:
            llm_span.set_attribute("llm.model", "gpt-4o")
            response = await llm.generate(message, docs)
            llm_span.set_attribute("llm.tokens", response.usage.total_tokens)

        span.set_attribute("response.length", len(response.text))
        return {"response": response.text}

# Usage in your agent
def track_request(func):
    """Decorator to track request metrics."""
    async def wrapper(*args, **kwargs):
        ACTIVE_REQUESTS.inc()
        start = time.time()
        try:
            result = await func(*args, **kwargs)
            REQUEST_COUNT.labels(status="success", model="gpt-4o").inc()
            return result
        except Exception as e:
            REQUEST_COUNT.labels(status="error", model="gpt-4o").inc()
            raise
        finally:
            duration = time.time() - start
            REQUEST_LATENCY.labels(endpoint="chat").observe(duration)
            ACTIVE_REQUESTS.dec()
    return wrapper

Cost Tracker

"""Cost tracking for AI agents."""

from dataclasses import dataclass
from datetime import datetime, timedelta
import json
from pathlib import Path

@dataclass
class CostEntry:
    timestamp: datetime
    model: str
    prompt_tokens: int
    completion_tokens: int
    cost_usd: float
    request_id: str
    user_id: str

class CostTracker:
    """Track and report AI agent costs."""

    # Pricing per 1M tokens
    PRICING = {
        "gpt-4o": {"input": 2.50, "output": 10.00},
        "gpt-4o-mini": {"input": 0.15, "output": 0.60},
        "claude-3-5-sonnet": {"input": 3.00, "output": 15.00},
        "claude-3-5-haiku": {"input": 0.25, "output": 1.25},
        "text-embedding-3-small": {"input": 0.02, "output": 0},
        "text-embedding-3-large": {"input": 0.13, "output": 0},
    }

    def __init__(self, log_path: str = "cost_log.jsonl"):
        self.log_path = Path(log_path)
        self.entries: list[CostEntry] = []

    def calculate_cost(self, model: str, prompt_tokens: int,
                       completion_tokens: int) -> float:
        """Calculate the cost of an LLM call."""
        pricing = self.PRICING.get(model)
        if not pricing:
            return 0.0

        input_cost = (prompt_tokens / 1_000_000) * pricing["input"]
        output_cost = (completion_tokens / 1_000_000) * pricing["output"]
        return input_cost + output_cost

    def log(self, model: str, prompt_tokens: int, completion_tokens: int,
            request_id: str, user_id: str = ""):
        """Log a cost entry."""
        cost = self.calculate_cost(model, prompt_tokens, completion_tokens)

        entry = CostEntry(
            timestamp=datetime.now(),
            model=model,
            prompt_tokens=prompt_tokens,
            completion_tokens=completion_tokens,
            cost_usd=cost,
            request_id=request_id,
            user_id=user_id,
        )
        self.entries.append(entry)

        # Append to log file
        with open(self.log_path, "a") as f:
            f.write(json.dumps({
                "timestamp": entry.timestamp.isoformat(),
                "model": model,
                "prompt_tokens": prompt_tokens,
                "completion_tokens": completion_tokens,
                "cost_usd": cost,
                "request_id": request_id,
                "user_id": user_id,
            }) + "\n")

        return cost

    def report(self, period: timedelta = timedelta(hours=24)) -> dict:
        """Generate a cost report for the given period."""
        cutoff = datetime.now() - period
        recent = [e for e in self.entries if e.timestamp >= cutoff]

        if not recent:
            return {"total_cost": 0, "requests": 0}

        total_cost = sum(e.cost_usd for e in recent)
        total_prompt = sum(e.prompt_tokens for e in recent)
        total_completion = sum(e.completion_tokens for e in recent)

        # Cost by model
        by_model = {}
        for entry in recent:
            if entry.model not in by_model:
                by_model[entry.model] = {"cost": 0, "requests": 0}
            by_model[entry.model]["cost"] += entry.cost_usd
            by_model[entry.model]["requests"] += 1

        # Cost by user
        by_user = {}
        for entry in recent:
            if entry.user_id not in by_user:
                by_user[entry.user_id] = 0
            by_user[entry.user_id] += entry.cost_usd

        return {
            "period_hours": period.total_seconds() / 3600,
            "total_cost_usd": round(total_cost, 4),
            "total_requests": len(recent),
            "avg_cost_per_request": round(total_cost / len(recent), 6),
            "total_prompt_tokens": total_prompt,
            "total_completion_tokens": total_completion,
            "by_model": by_model,
            "top_users_by_cost": dict(
                sorted(by_user.items(), key=lambda x: x[1], reverse=True)[:10]
            ),
        }

    def check_budget(self, daily_budget: float = 100.0) -> dict:
        """Check if we're within budget."""
        report = self.report(timedelta(hours=24))
        cost = report["total_cost_usd"]
        return {
            "budget_usd": daily_budget,
            "spent_usd": cost,
            "remaining_usd": round(daily_budget - cost, 4),
            "percent_used": round((cost / daily_budget) * 100, 1),
            "on_track": cost < daily_budget,
        }

14.9 Caching Strategies

Semantic Caching

"""Semantic caching - cache based on meaning, not exact text."""

import numpy as np
from sentence_transformers import SentenceTransformer

class SemanticCache:
    """Cache responses based on query similarity."""

    def __init__(self, similarity_threshold: float = 0.92):
        self.model = SentenceTransformer("all-MiniLM-L6-v2")
        self.cache: list[dict] = []
        self.threshold = similarity_threshold

    def _embed(self, text: str) -> list[float]:
        return self.model.encode([text])[0].tolist()

    def _similarity(self, a: list[float], b: list[float]) -> float:
        a, b = np.array(a), np.array(b)
        return float(np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b)))

    def get(self, query: str) -> dict | None:
        """Find a cached response for a semantically similar query."""
        query_embedding = self._embed(query)

        for entry in self.cache:
            sim = self._similarity(query_embedding, entry["embedding"])
            if sim >= self.threshold:
                return {
                    "response": entry["response"],
                    "cached": True,
                    "similarity": sim,
                    "original_query": entry["query"],
                }

        return None

    def set(self, query: str, response: str):
        """Cache a query-response pair."""
        self.cache.append({
            "query": query,
            "response": response,
            "embedding": self._embed(query),
            "timestamp": time.time(),
        })

    def clear_old(self, max_age_seconds: int = 3600):
        """Remove stale cache entries."""
        cutoff = time.time() - max_age_seconds
        self.cache = [e for e in self.cache if e["timestamp"] > cutoff]

import redis
import hashlib
import json

class ResponseCache:
    """Redis-based response cache with TTL."""

    def __init__(self, redis_url: str = "redis://localhost:6379"):
        self.redis = redis.from_url(redis_url)
        self.default_ttl = 3600  # 1 hour

    def _key(self, query: str, model: str) -> str:
        content = f"{model}:{query}"
        return f"rag_cache:{hashlib.sha256(content.encode()).hexdigest()}"

    def get(self, query: str, model: str) -> dict | None:
        """Get cached response."""
        key = self._key(query, model)
        cached = self.redis.get(key)
        if cached:
            return json.loads(cached)
        return None

    def set(self, query: str, model: str, response: dict, ttl: int = None):
        """Cache a response."""
        key = self._key(query, model)
        self.redis.setex(
            key,
            ttl or self.default_ttl,
            json.dumps(response),
        )

    def invalidate(self, pattern: str = "rag_cache:*"):
        """Invalidate cache entries matching pattern."""
        keys = self.redis.keys(pattern)
        if keys:
            self.redis.delete(*keys)

    def stats(self) -> dict:
        """Get cache statistics."""
        keys = self.redis.keys("rag_cache:*")
        return {
            "total_entries": len(keys),
            "memory_used": self.redis.info("memory")["used_memory_human"],
        }

14.10 Rate Limiting

"""Rate limiting for AI agents."""

import time
from collections import defaultdict

class RateLimiter:
    """Token bucket rate limiter."""

    def __init__(self, max_requests: int, window_seconds: int = 60):
        self.max_requests = max_requests
        self.window = window_seconds
        self.requests: dict[str, list[float]] = defaultdict(list)

    def allow(self, identifier: str) -> dict:
        """Check if a request is allowed."""
        now = time.time()
        window_start = now - self.window

        # Clean old entries
        self.requests[identifier] = [
            t for t in self.requests[identifier] if t > window_start
        ]

        current = len(self.requests[identifier])

        if current >= self.max_requests:
            retry_after = self.requests[identifier][0] + self.window - now
            return {
                "allowed": False,
                "remaining": 0,
                "retry_after_seconds": max(0, retry_after),
            }

        self.requests[identifier].append(now)
        return {
            "allowed": True,
            "remaining": self.max_requests - current - 1,
            "retry_after_seconds": 0,
        }

class CostRateLimiter:
    """Rate limit based on API cost, not just request count."""

    def __init__(self, daily_budget: float = 50.0):
        self.daily_budget = daily_budget
        self.spent_today: dict[str, float] = defaultdict(float)
        self.reset_date = time.strftime("%Y-%m-%d")

    def check_budget(self, user_id: str, estimated_cost: float) -> dict:
        """Check if user is within their budget."""
        # Reset daily
        today = time.strftime("%Y-%m-%d")
        if today != self.reset_date:
            self.spent_today.clear()
            self.reset_date = today

        current_spend = self.spent_today[user_id]
        if current_spend + estimated_cost > self.daily_budget:
            return {
                "allowed": False,
                "reason": "daily_budget_exceeded",
                "current_spend": current_spend,
                "budget": self.daily_budget,
            }

        self.spent_today[user_id] += estimated_cost
        return {
            "allowed": True,
            "current_spend": self.spent_today[user_id],
            "budget": self.daily_budget,
        }

        await self._save_history(conversation_id, message, response)

                           assistant_msg: str):

        # Save to database
        await self.db.save_message(conversation_id, "user", user_msg)
        await self.db.save_message(conversation_id, "assistant", assistant_msg)

        # Update Redis cache
        history = await self._load_history(conversation_id)
        history.append({"role": "user", "content": user_msg})
        history.append({"role": "assistant", "content": assistant_msg})
        self.redis.setex(
            f"conv:{conversation_id}",
            3600,  # 1 hour TTL
            json.dumps(history),
        )

"""Complete tracing implementation for AI agents."""

import time
import uuid
import json
from dataclasses import dataclass, field, asdict
from typing import Any
from contextlib import asynccontextmanager

@dataclass
class Span:
    """A single span in a trace."""
    name: str
    start_time: float = field(default_factory=time.time)
    end_time: float = 0.0
    attributes: dict[str, Any] = field(default_factory=dict)
    status: str = "ok"
    children: list["Span"] = field(default_factory=list)

    def finish(self, status: str = "ok"):
        self.end_time = time.time()
        self.status = status

    @property
    def duration_ms(self) -> float:
        if self.end_time == 0:
            return (time.time() - self.start_time) * 1000
        return (self.end_time - self.start_time) * 1000

    def to_dict(self) -> dict:
        return {
            "name": self.name,
            "duration_ms": round(self.duration_ms, 2),
            "status": self.status,
            "attributes": self.attributes,
            "children": [c.to_dict() for c in self.children],
        }

@dataclass
class Trace:
    """A complete trace of an agent interaction."""
    trace_id: str = field(default_factory=lambda: str(uuid.uuid4())[:12])
    start_time: float = field(default_factory=time.time)
    spans: list[Span] = field(default_factory=list)
    attributes: dict[str, Any] = field(default_factory=dict)

    @asynccontextmanager
    async def span(self, name: str, **attributes):
        """Context manager for creating spans."""
        s = Span(name=name, attributes=attributes)
        self.spans.append(s)
        try:
            yield s
        except Exception as e:
            s.finish(status="error")
            s.attributes["error"] = str(e)
            raise
        else:
            s.finish()

    @property
    def total_duration_ms(self) -> float:
        return (time.time() - self.start_time) * 1000

    def to_dict(self) -> dict:
        return {
            "trace_id": self.trace_id,
            "total_duration_ms": round(self.total_duration_ms, 2),
            "attributes": self.attributes,
            "spans": [s.to_dict() for s in self.spans],
        }

    def to_json(self) -> str:
        return json.dumps(self.to_dict(), indent=2)

    def log_summary(self):
        """Print a summary of the trace."""
        print(f"\n{'='*60}")
        print(f"TRACE {self.trace_id}")
        print(f"{'='*60}")
        for span in self.spans:
            status_icon = "OK" if span.status == "ok" else "ERR"
            print(f"  [{status_icon}] {span.name}: {span.duration_ms:.0f}ms")
            for key, value in span.attributes.items():
                print(f"       {key}: {value}")
        print(f"  TOTAL: {self.total_duration_ms:.0f}ms")
        print(f"{'='*60}\n")

"""Complete caching layer for RAG systems."""

import hashlib
import json
import time
import numpy as np
from sentence_transformers import SentenceTransformer

class RAGCacheLayer:
    """Multi-level caching for RAG pipelines."""

    def __init__(self, redis_client=None, similarity_threshold: float = 0.92):
        self.redis = redis_client
        self.similarity_threshold = similarity_threshold
        self.embed_model = SentenceTransformer("all-MiniLM-L6-v2")

        # In-memory cache as L1 (fastest)
        self.l1_cache: dict[str, dict] = {}
        self.l1_max_size = 1000

        # Statistics
        self.stats = {"hits": 0, "misses": 0, "l1_hits": 0, "l2_hits": 0}

    async def get(self, query: str) -> dict | None:
        """Try to find a cached response."""
        # L1: Exact match (in-memory)
        exact_key = self._exact_key(query)
        if exact_key in self.l1_cache:
            entry = self.l1_cache[exact_key]
            if not self._is_expired(entry):
                self.stats["hits"] += 1
                self.stats["l1_hits"] += 1
                return {**entry["response"], "cache_level": "L1_exact"}

        # L2: Semantic match (in-memory)
        query_emb = self.embed_model.encode([query])[0]
        for key, entry in self.l1_cache.items():
            if not self._is_expired(entry):
                sim = self._similarity(query_emb, entry["embedding"])
                if sim >= self.similarity_threshold:
                    self.stats["hits"] += 1
                    self.stats["l1_hits"] += 1
                    return {
                        **entry["response"],
                        "cache_level": "L1_semantic",
                        "similarity": sim,
                    }

        # L3: Redis cache (if available)
        if self.redis:
            redis_result = self._redis_get(query)
            if redis_result:
                self.stats["hits"] += 1
                self.stats["l2_hits"] += 1
                return {**redis_result, "cache_level": "L2_redis"}

        self.stats["misses"] += 1
        return None

    async def set(self, query: str, response: dict, ttl: int = 3600):
        """Cache a query-response pair."""
        entry = {
            "query": query,
            "response": response,
            "embedding": self.embed_model.encode([query])[0].tolist(),
            "timestamp": time.time(),
            "ttl": ttl,
        }

        # Store in L1
        if len(self.l1_cache) >= self.l1_max_size:
            # Evict oldest
            oldest_key = min(self.l1_cache, key=lambda k: self.l1_cache[k]["timestamp"])
            del self.l1_cache[oldest_key]

        self.l1_cache[self._exact_key(query)] = entry

        # Store in L2 (Redis)
        if self.redis:
            self._redis_set(query, response, ttl)

    def _exact_key(self, query: str) -> str:
        return hashlib.sha256(query.lower().strip().encode()).hexdigest()

    def _similarity(self, a: np.ndarray, b: list[float]) -> float:
        b = np.array(b)
        return float(np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b)))

    def _is_expired(self, entry: dict) -> bool:
        return time.time() - entry["timestamp"] > entry.get("ttl", 3600)

    def _redis_get(self, query: str) -> dict | None:
        key = f"rag:{self._exact_key(query)}"
        cached = self.redis.get(key)
        return json.loads(cached) if cached else None

    def _redis_set(self, query: str, response: dict, ttl: int):
        key = f"rag:{self._exact_key(query)}"
        self.redis.setex(key, ttl, json.dumps(response))

    def get_stats(self) -> dict:
        total = self.stats["hits"] + self.stats["misses"]
        return {
            **self.stats,
            "hit_rate": f"{(self.stats['hits']/total*100):.1f}%" if total > 0 else "0%",
            "l1_entries": len(self.l1_cache),
        }

14.16 Key Takeaways

  1. Observability is not optional. You cannot debug what you cannot see. Add logging, metrics, and tracing from day one.

  2. Log everything that matters. User inputs, RAG retrieval scores, LLM calls, tool invocations, errors, and costs. Use structured logging (JSON), not plain text.

  3. Distributed tracing reveals the full picture. When a request flows through RAG, LLM, tools, and back, you need to see the entire journey. Use OpenTelemetry or LangSmith.

  4. Track costs relentlessly. LLM costs can spiral. Track per-request, per-user, per-model costs. Set budget alerts.

  5. Cache aggressively. Semantic caching, response caching, and embedding caching can reduce costs by 50%+ and latency by 90%+.

  6. Stream responses. Users perceive streaming as instant. Never make them wait for the full response.

  7. Rate limit by cost, not just count. One expensive GPT-4o call costs more than 100 GPT-4o-mini calls. Limit by budget.

  8. Scale statelessly. Store all state externally (Redis, PostgreSQL, vector store). Any instance can handle any request.

  9. Auto-scale on the right metrics. CPU and memory are good. Active requests per instance is better for AI workloads.

  10. Build dashboards for action. Every number on your dashboard should trigger a decision: scale up, investigate, or celebrate.
