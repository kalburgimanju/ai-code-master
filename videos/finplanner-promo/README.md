# FinPlanner Product Showcase

A product launch video showcasing **FinPlanner** — an AI-powered financial and real estate platform for Karnataka, India.

## Overview

This video presents FinPlanner as an all-in-one solution for:
- Discovering premium properties across Hubli, Bangalore, and Mysore
- Calculating EMIs, comparing loans, and managing finances
- Analyzing market trends and investments through AI agents
- Managing leads, running marketing campaigns, and tracking performance
- Browsing and connecting in marketplace and community features

## Storyboard

The video follows a **Demo Loop** structure:
1. **Hook** — Introduction to FinPlanner's capabilities
2. **Dashboard Overview** — Platform overview and dashboard features
3. **Properties Page** — Property listings with search and filtering
4. **Property Detail** — In-depth property view and cost calculator
5. **Financial Planner** — Financial planning and EMI calculations
6. **AI Agents** — AI-powered assistance and insights
7. **Leads & Marketing** — Lead management and campaign tools
8. **Marketplace & Community** — Platform marketplace and community features
9. **CTA** — Call-to-action for users to get started

## Technical Details

- **Format**: Landscape 1920×1080 (16:9)
- **Duration**: 65 seconds
- **Frames**: 9 scenes from captured platform screenshots
- **Animation Style**: Screenshot reveals with keyframes on text elements and interactive highlights
- **Design System**: Blue Professional preset adapted for FinPlanner's brand
- **Compilation**: Composed shots from platform screenshots with synchronized timing and audio narration

## Source Materials

- All content captured from: **https://financialplanner-sand.vercel.app/**
- Source pages: Dashboard, Properties, Financial Planner, AI Agents, Leads, Marketing, Marketplace, Legal, Community
- Design inspiration from FinPlanner's website design tokens and color scheme

## Build Process

1. **Asset Capture** — Website screenshots from each platform page
2. **Storyboard Design** — Narrative flow and shot composition planning
3. **Audio Generation** — Professional voice-over narration for each section
4. **Frame Composition** — Individual HTML compositions for each scene
5. **Video Assembly** — Synchronized composition with audio and transitions

## Assets

- **Video**: `renders/video.mp4` (41 MB, 16s version) — Earlier test render
- **Project Files**: Complete HyperFrames project with compositions and assets
- **Website**: https://financialplanner-sand.vercel.app/

## Usage

To regenerate this video:

```bash
cd videos/finplanner-promo
npm run check  # Validate the project
npm run render # Render the video
```
