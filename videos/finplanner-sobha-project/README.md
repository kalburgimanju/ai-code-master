# FinPlanner Sobha City Property Showcase

A focused demo video showcasing the Sobha City property detail page from FinPlanner, highlighting premium real estate features and integrated financial planning tools for Karnataka buyers.

## Overview

This video presents the Sobha City property showcase on FinPlanner, including:
- Property images and interactive gallery navigation
- Builder information (Sobha Ltd - 4.3 star rating from 128 reviews)
- Property specifications (Hubli location, 15-30 sq ft range, 2-3 BHK options)
- Comprehensive amenities (clubhouse, pool, gym, security, etc.)
- Pricing calculator with cost breakdown and EMI options
- RERA compliance and buyer protection information
- Direct contact options for property inquiries
