# HeyGen Prompt Guide Video

**Product:** HeyGen Video Agent Prompt Guide
**Goal:** 30-40s promotional/educational video about the HeyGen prompt guide
**Tone:** Professional, helpful, practical
**Target:** Knowledge workers creating explainer videos

## Intent
Show viewers the real, stealable prompts from the HeyGen prompt guide — from basic content prompts to scene-by-scene control — so they can immediately improve their Video Agent results.

## Scenes
1. **Hero (0-6s)** — Title: "HeyGen Video Agent: Prompts That Work"
2. **Basic Prompts (6-12s)** — The 3 controls + basic content prompts
3. **Pro Prompts (12-20s)** — Full script paste + advanced style + scene-by-scene
4. **Scene-by-Scene (20-27s)** — The 8-scene product launch structure
5. **CTA (27-35s)** — "Try these prompts. You write the message. The Video Agent produces it."

## Voice-over Script
### Scene 1: Hero
"The HeyGen Video Agent prompt guide has real, stealable prompts. Here's what you need to know to get amazing results."

### Scene 2: Basic Prompts
"Three basic controls: avatar selection, duration, and aspect ratio. Start with a basic content prompt describing your video, or use the pro move — paste a full script."

### Scene 3: Advanced Prompts
"Go further with advanced style prompts using hex codes and fonts, or upload attachments and tell the agent exactly how to use them."

### Scene 4: Scene-by-Scene
"For maximum control, structure each scene with type, visuals, voice-over, and duration. An eight-scene product launch: intro motion graphics, avatar hook, problem, solution, features, benefits, CTA, and end card."

### Scene 5: CTA
"You had the message. Now you own the production. Try these prompts and see what the Video Agent can do for you."
